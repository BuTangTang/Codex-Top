## 范围和交互

- Windows 11 x64 为当前实际验证目标；在其他系统、ARM64 和 WSL 上的行为单独验证后再声明支持。
- 中文紧凑桌面工具，四种模式共享关注列表：顶部摘要、常驻浮窗、44 DIP 圆环、仅托盘。
- 圆环点击展开，移开不关闭，外部点击或 Escape 收回；浮窗保持置顶，可从标题空白处拖动。退出浮窗回到进入前模式。
- 搜索和选择任务，自动关注新开始任务，手动排除优先；子任务状态聚合到主任务，跳转使用提供状态的任务。
- 显示运行、等待、失败、完成、停止、未知；缺失时间不估计，等待耗时停止增长。
- 明暗主题、60%–120% 每 5% 缩放、1–12 条可见任务、暂停任务刷新、选择数据目录和 CLI。
- 显示真实返回的账户额度周期、剩余比例、更新时间、重置时间。读取失败显示不可用。

## 技术设计

采用 C# / .NET 10 / WPF。Windows 原生窗口负责置顶、焦点和 DPI；Windows Forms NotifyIcon 提供托盘。业务核心独立于界面。当前机器无 SDK，项目内 `.tools/dotnet` 安装官方 .NET SDK，不修改全局 PATH。

数据流：只读 SQLite 任务元数据 → 按文件偏移增量读取 rollout → 按明确事件归约状态 → 聚合父子任务 → 关注策略 → 共用界面模型。数据库使用 Windows 系统 SQLite 的只读打开方式；不建立或迁移 Codex 表结构。

应用偏好单独存放在本用户的 LocalAppData/CodexTop/settings.json，内容为显示设置、任务 ID 选择、自动关注基线和用户选择的数据源。任务正文与认证信息不作为应用持久化内容。

额度通过独立 Codex CLI `app-server --stdio` 连接，执行 initialize、initialized、account/rateLimits/read；自动约 60 秒，手动至少 5 秒，单次 15 秒超时，取消时回收本工具启动的子进程。监控链路不创建或发送任务。

## 版本差异

Windows 交接文档比源码旧。以最新确定规则为准：右上角“＋ / ⋯”、退出常驻浮窗返回上一个模式、可见任务数 1–12。Windows 的窗口与平台实现必须独立验证。

## 0.1.1 局部修复

用户提供截图要求去掉圆环周围的方形底色，最小化只留右下角托盘，不显示任务栏入口。按 L1 修复窗口显示层：圆环禁用矩形系统背景，使用原生椭圆裁剪和不透明圆形填充；主窗口及设置、选择窗口统一关闭任务栏入口；增加直接最小化到托盘操作，隐藏的设置/选择窗口可以从原菜单恢复。没有改动数据读取、任务状态或持久化结构。验证证据见验证记录的 0.1.1 部分。

## 0.1.2 跨屏缩放修复

需求：用户反馈圆环在两块显示器之间切换后出现错位的黑色/彩色边缘。按 L2 修复多个窗口交互状态，不改变数据接口或偏好文件结构。

实测环境为 DISPLAY1：1920×1080、120 DPI（125%）；DISPLAY2：2560×1440、96 DPI（100%），第二屏左上角为 (-2560,-139)。原版缺少 DPI 变化后的裁剪更新，44 像素客户区仍使用旧的约 54 像素区域；还存在 WPF Left/Top 在 DPI 切换阶段与实际像素位置不同步的问题。

设计与实施：保留 WPF 的 PerMonitorV2 缩放和状态所有者；收到 DPI 变化后，在布局完成阶段停止旧尺寸动画、重排、更新原生裁剪并重绘；裁剪不能大于当前客户区。屏幕移动和边界约束使用物理像素，圆环锚点从原生位置换算，按 DPI 变化重算；拖动面板使用物理位移，托盘恢复先进入目标屏幕再计算偏移。圆环矢量绘制随 DPI 刷新。

验收与状态：增加独立 Windows 集成测试，先在旧实现复现裁剪错误，再验证修改版本；发现并修复往返回 125% 后展开/收起的位置偏移。当前实际两屏往返、圆环/面板裁剪、展开收起锚点与最小化恢复 54 项断言通过。已逐块检查尺寸动画、拖动、显示模式、托盘恢复、显示配置变化和关闭回调链路。核心读取和状态代码未改。完整鼠标跨屏拖动手感、物理拔插和休眠场景仍与程序化窗口切换检查区分。

## 0.1.3 圆环点状黑边修复

用户反馈跨屏几何修复后仍有点状黑色外圈。L1 局部绘制修复：原生窗口采用不透明表面和椭圆区域裁剪，WPF 圆角边缘却保留半透明像素，导致透出原生黑色底层。圆环模式下使整个窗口客户区填充当前圆环底色，去掉额外的外框描边；区域外仍被原生椭圆裁掉。展开面板恢复透明窗口底色，保持原有背景效果。等待/失败的呼吸效果也有一致的实色底层。

补充了根据实际 GDI 圆形区域取样的边缘像素回归，先在旧版复现 8 项失败，再确认 62 项检查全部通过。在独立测试窗口上通过 Computer Use 查看实际外观，未见原截图的点状黑边。已反查颜色切换、圆环/面板切换和关闭测试窗口路径；任务数据、位置与账户处理未修改。

## 0.1.4 展开面板外框修复

用户要求展开面板去除灰黑矩形外框，只保留内部白色圆角部分。L1 局部修复：关闭所有监控窗口的矩形系统背景、延伸窗框及非客户区绘制；浅色面板改为实色白色，客户区与内容使用同色填充，移除内容外描边。原生裁剪的圆角直接取内容圆角，覆盖常驻浮窗和缩放后的面板。界面中的“浅色玻璃”改为“浅色”。

沿用跨屏与圆环测试，增加展开面板的系统背景状态、四角裁剪和边缘像素检查；旧版 8 项失败，修复后 74 项全部通过。通过独立测试窗口实际查看常驻白色圆角面板，未见截图中的矩形底框。未修改任务数据、状态处理或偏好结构，未提交或远程发布。

## 0.1.5 圆角菜单与明暗透明边缘

用户要求截图中的右键设置菜单柔和圆角，并修复深色主题下仍出现的外缘问题。按 L2 界面修复，涉及菜单、设置、主题切换及圆环/面板多个状态，不改变任务、账户或偏好数据结构。

0.1.3–0.1.4 使用同色实底解决黑色底层，但 GDI 窗口区域仍是硬裁剪，在深色圆环上留下明显锯齿。本版替换这一绘制方案：主窗口启用 WPF 逐像素透明，窗口底色透明，取消 GDI 区域，保留内容圆角及实色填充、禁用系统矩形底框。透明边缘由 WPF 抗锯齿合成；此前跨屏 DPI、物理坐标和锚点修复继续保留。

新增共用控件资源，右键菜单和子菜单使用圆角透明弹层；设置中的下拉框、输入框、复选框和滚动条统一配色。设置与任务选择窗口使用动态主题资源并更新标题栏；主题选择同步已有窗口，无需关闭重开。菜单命令、键盘导航、设置保存及托盘行为延续原链路。

实施与验收：检查真实 120/96 DPI 两屏往返中的两种主题、展开收起、透明外角、边缘颜色、设置同步和托盘恢复；通过 Computer Use 查看实际菜单、设置、圆环和面板。完成累计差异审查并本地更新 0.1.5 运行包与源码包，具体证据和限制见验证记录。未提交、推送或远程发布。

## 0.1.6 展开面板外部点击收起

用户反馈临时展开面板有时点击外部后仍不回到圆环。检查当前显示偏好为桌面圆环模式。按 L2 交互修复，涉及临时展开、菜单、设置和任务选择窗口的焦点交接。

原逻辑只在主窗口失焦时检查一次，并被菜单打开、设置或选择窗口可见等条件直接阻止；菜单关闭和子窗口失焦后未补查。改为在主/子窗口失焦、子窗口隐藏关闭、菜单关闭及拖动结束后安排 80ms 单次检查，按 Windows 前台窗口的所属关系判断是否仍在操作本工具。操作自身对话框时保持展开，留在后台的对话框不再阻止收起。

菜单捕获期间保留外部点击/失焦意图，防止关闭菜单后的焦点恢复掩盖收起请求；菜单命令和重新点击内部可以覆盖该请求。继续使用原状态与收起动画：桌面圆环返回 44 DIP，托盘展开返回隐藏状态，常驻浮窗保持常驻。没有新增全局输入监听或更改数据、偏好结构。

验收覆盖失焦后收起、设置/任务选择器留在后台、隐藏设置、菜单关闭补查、内部焦点交接、快速切回、所属对话框以及托盘/常驻模式。通过本机两屏回归和 Computer Use 实际点击检查，具体证据见验证记录。本地更新 0.1.6 运行包与源码包，未提交、推送或远程发布。

## 0.1.7 当前面板直接取消关注

用户要求在当前任务面板直接取消任务，无需进入“＋”选择器。按已有入口解释为取消关注，按 L2 交互调整：为所有状态的任务行增加独立的“× / 取消关注”按钮，包含展开后的已结束列表；保持点击任务内容返回 Codex 的行为。

按钮与任务跳转区并列，避免鼠标或键盘事件触发任务导航。复用 MonitoringPolicy.ApplySelection 对根任务取消关注并加入手动排除，再由现有保存与通知链路刷新界面。不会终止、删除或修改 Codex 任务，自动关注不会把手动移除的任务重新加入，仍可通过“＋”恢复关注。

已有选择器同步外部关注变化时，重建选择基线并保留用户尚未提交的增删草稿，防止新增快捷入口造成过期勾选或覆盖其他修改。未改偏好文件结构或数据源。针对性验证覆盖持久化、排除规则、草稿合并、重新加入和空列表，并通过实际点击检查入口。详见验证记录。本地更新 0.1.7 运行包与源码包，未提交、推送或远程发布。

## 0.1.8 圆环悬停缩放

用户希望鼠标放上圆环时有伸缩放大的感觉。按 L2 界面交互调整，涉及圆环悬停、拖动、菜单和展开收起的动画交接，保持现有任务与账户链路。

圆环可见常态仍为 44 DIP，在 56 DIP 的透明窗口内居中，四周各留 6 DIP，避免放大越过窗口边界。悬停使用独立缩放变换，约 200ms 放大至 1.12 倍，移开约 260ms 平滑回到原尺寸，反复进出从当前比例续接，不叠加动画。窗口位置及尺寸不随悬停改变。等待/失败的呼吸效果转到圆环内部，避免外轮廓和鼠标命中区域反复缩小。

拖动期间和打开菜单时恢复常态；离开圆环模式清除悬停变换。遵循应用“减少动态效果”及 Windows 动画偏好。展开面板不留圆环透明边距，收起后恢复预留空间；跨屏仍使用既有原生坐标和 DPI 处理。没有改变偏好数据结构，也未增加常驻计时器。

验收覆盖明暗两主题下的放大/缩回、轮廓透明边缘与无裁切、原生窗口坐标稳定、展开收起和菜单/对话框焦点行为，并实际检查鼠标点击及拖动。具体证据与未验范围见验证记录。本地更新 0.1.8 便携包和源码包，未提交、推送或远程发布。
