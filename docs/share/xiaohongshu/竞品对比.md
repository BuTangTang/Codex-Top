核对日期：2026-09-12。用途是为分享文案说明产品侧重。范围为各项目公开 README 与 Codex Top 当前代码及窗口截图，未安装、操作或测量竞品；“简单”是本项目的设计目标，不是完成横向可用性测试后的排名。

| [Atoll](https://github.com/Ebullioscopic/Atoll#highlights) | 音乐、计时、剪贴板和系统信息等综合功能 | 刘海交互与锁屏组件 | 适合希望刘海整合多种日常工具的使用方式；Codex Top 集中于 Codex 任务。 |

以上是各项目文档列出的主要入口，不是穷尽全部功能的支持/不支持矩阵。CodexBar 也有简洁界面、桌面组件及更多功能，不能写成“其他产品都复杂”或“只能用菜单栏”。Atoll 指 `Ebullioscopic/Atoll`，不混用同名项目或其他分支的 AI 会话功能。CodexNotch 的额度环/波浪球是刘海额度指示器，不能直接等同本项目可拖动的桌面任务圆环。

## 分享时强调什么

**简单**：专注任务监控。选择关注任务，新建并开始的任务默认自动加入；待处理优先显示，已结束可折叠。不把“简单”写成零前提：需要本机 Codex 的任务记录，账户额度还需要已登录的官方 CLI。

**多种方式**：四种模式共用一份关注列表。希望持续看到列表就用浮窗，希望占地小就用圆环，也可选择刘海或仅状态栏。切换位置不必重新选一遍任务。

适合对外的一句话：**Codex Top 是一个专注 Codex 任务监控的原生 Mac 小工具，用简单的操作，在刘海、浮窗、圆环和状态栏之间切换同一份关注列表。**
