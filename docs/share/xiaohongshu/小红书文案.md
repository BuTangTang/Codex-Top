# 给 Codex 做了个桌面小挂件

最近做了一个原生 macOS 小工具：**Codex Top**。

同时跑几个 Codex 任务时，总要切回去看：还在运行，还是已经在等我确认？于是把关注的任务放到了屏幕边上，抬眼就能看一眼进展。

它可以放在刘海附近，也可以变成常驻浮窗、小圆环，或者只留在状态栏。

🔵 运行中的任务，显示状态和计时。
🟠 需要回复或确认的任务，优先排在前面。
📌 支持搜索、多选，按自己的节奏关注任务。
🫧 浅色玻璃 / 深色主题，可拖动、可调整显示比例。

只读本地任务记录，不上传任务内容。状态以本机记录为准，回复和批准仍然在 Codex 里完成。

目前支持 macOS 14+，已经开源。还在持续打磨，欢迎同样在用 Codex 的朋友试试。
