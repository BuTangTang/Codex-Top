# 给 Codex 做个简单的桌面小挂件

最近做了一个原生 macOS 小工具：**Codex Top**。

同时跑几个 Codex 任务时，总要切回去看：还在运行，还是已经在等我确认？我想把这件事做得简单一点。

**简单看任务，自由选位置。**

关注正在做的任务，运行和待处理状态集中显示；新建并开始的任务默认自动加入，历史任务也能搜索、多选。

同一份关注列表，可以在四种显示方式之间切换：

- **刘海模式**：放在屏幕顶部，悬停展开。
- **常驻浮窗**：一直放在旁边，拖到顺手的位置。
- **圆环模式**：收成 44pt 小圆环，需要时再点开。
- **仅状态栏**：收起桌面面板，从菜单栏查看。

看过几款同类工具的公开介绍：CodexBar 侧重多平台额度和用量，CodexNotch 把 Codex 额度与任务放到刘海附近，Atoll 则提供音乐、计时、系统信息等综合功能。Codex Top 更贴近我的需求：**专注 Codex 任务监控，用简单的操作选择关注内容和显示方式。**

浅色玻璃 / 深色主题，可调整显示比例。只读本地任务记录，不上传任务内容；状态以本机记录为准，回复和批准仍在 Codex 里完成。

目前支持 macOS 14+，已经开源。还在持续打磨，欢迎同样在用 Codex 的朋友试试。
