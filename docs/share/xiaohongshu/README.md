## 来源与隐私

- 继续使用前轮已核对的 v0.1.0、build 2 独立 Demo 副本。真实实例先退出，截图副本使用合成任务和独立偏好，不读取真实任务或账户额度。产品源码和安装包未修改。
- 背景来自系统自带 Sonoma 壁纸的深色帧，以临时预览窗口展示；系统桌面壁纸设置未改变。只截取壁纸内部的安全区域，画面不包含预览窗口标题栏、私人桌面文件、账号或菜单栏。
- 旧版本使用低分辨率窗口预览，放大后不清楚。用户明确同意改用 macOS 原生截图命令后，本轮使用原生区域捕获保留 Retina 2 倍像素，清除鼠标提示后重新拍摄。
- 圆环使用应用自带“运行”预览，显示 4 个运行任务；展开与钉住使用默认混合示例，显示 2 个运行任务、1 个待处理和1个已结束。它们是不同示例状态的截图。
- 所有图片已目视核对，并检查 OCR 隐私关键词和元数据，没有检出本机完整路径、私人账号或敏感元数据。公开图中任务均为示例，展开和浮窗保留应用内演示标识。
- 结束后截图副本退出，原 Demo 偏好逐字节恢复，临时壁纸窗口和新增访达标签页关闭。真实版恢复且完整偏好与拍摄前一致，仅保留一个真实实例，鼠标提示服务已清理。
- 本轮在内置 Retina 屏拍摄，不替代外接屏或完整动画验收。110 项测试及 release 构建通过。
