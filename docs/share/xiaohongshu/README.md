## 重新导出

在仓库根目录执行：

```sh
swift docs/share/xiaohongshu/render.swift
```

使用 macOS AppKit 排版，SwiftUI 连续圆角匹配真实窗口外轮廓，去除截图矩形角落的底色。源截图不改字、不锐化、不重绘。原始圆环、展开面板、浮窗分别为 44 × 44、369 × 261、324 × 189 像素；1080 × 1080 是排版画布尺寸，小窗口的清晰度仍受源图限制。

本轮 `swift test` 110 项、`swift build -c release` 均通过，两张成图已实际渲染并检查文字边界。当前分享包只含两张效果图和精简文案，未改动软件功能或 Release 附件。
