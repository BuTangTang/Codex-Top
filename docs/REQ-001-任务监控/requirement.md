# REQ-001 任务监控

## 目标

用户不用持续切回 Codex，就能看到关注任务的活动、待处理事项与最近完成情况；支持在刘海附近展开和悬浮置顶。第一版交付可构建、可运行的原生 macOS 应用、测试、使用说明和真实验收记录。

## 已确认决策

- D-01：重建紧凑界面。保留刘海总览和紧凑浮窗，避免单任务大卡片。
- D-02：所有显示模式共用一份监控列表，图钉仅放在顶部，不再按任务分别钉住。
- D-03：历史任务支持搜索、多选、全选当前筛选结果；新建并开始运行的任务默认自动加入。
- D-04：首次启动纳入正在活动和明确待处理的任务；子任务归入主任务；完成任务可折叠。
- D-05：使用 Swift、SwiftUI、AppKit；Codex 数据只读，工具自己的设置独立保存。
- D-06：项目开源在 BuTangTang/Codex-Top，用户已选 GPL v3；实现和文档同步，阶段性提交并 push。
- D-07：任务创建和回答、批准操作仍在 Codex 中完成；监控界面提供返回对应任务的入口。
- D-08：用户会外接屏幕。多显示器、合盖/断开后的恢复是正式功能；关键决定与已做/待做工作持续写入项目状态文档。
- D-09：以 `docs/design/main.png` 和 `picker.png` 为视觉基准，不能只改颜色便认为完成。中文工具栏、磨砂蓝灰材质、蓝色运行环、琥珀色等待提示、任务名称/说明的层次必须还原。
- D-10：用户反馈文字难读，同时拒绝整体面板放大。当前取展开任务名 15pt、浮窗 14pt、说明/计时 12pt，菜单条 13pt；通过文字对比度和紧凑间距兼顾可读性与占屏面积。
- D-11：鼠标移到顶部自动展开，进入列表后保持；离开约 400ms 后收起。置顶浮窗不因鼠标离开而隐藏。
- D-12：提供深/浅两种透明玻璃配色；不能只淡入内容，主体轮廓与尺寸变化也要有类似 macOS 的连续动画。参考 Atoll。先在桌面演示应用中试效果。
- D-13：用户确认只做 Codex 专用工具，继续使用独立的 Codex Top 工程。Atoll 单独克隆到仓库外作设计与实现参考，不以整个 Atoll 工程作为产品基础，不扩展音乐、天气、剪贴板或系统监控功能。
- D-14：用户要求背景和字体按 Atoll。深色默认采用纯黑背景、系统字体、白色主文字和中性灰辅助文字，替代此前偏蓝灰材质；浅色玻璃保留为可选配色。标题使用系统 rounded semibold 16pt、任务名 medium 14pt、辅助说明 12pt。
- D-15：用户反馈新版动画仍偏慢，要求更流畅、更快；新增 80%/90%/100% 显示比例、可拖动常驻桌面小浮窗、靠近顶部松手后自动吸附，以及仅状态栏显示方式。浮窗移开鼠标后不收起。先提供常驻小浮窗概念图 `docs/design/desktop-compact-v1.png`，不把图片当成已经实现/验收的功能。

- D-16：新增仅圆环显示，常驻桌面的小圈可拖动，悬停/点击查看同一份列表；接近顶部拖放可收进状态栏。圆环固定 44pt，列表可选 80%/90%/100%。

D-14–D-16 是最新视觉与交互决定，覆盖 D-09–D-12 中旧的蓝灰材质、字号与 400ms 离开等待。当前采用纯黑/浅色玻璃、14pt 任务名与 180ms 离开等待；这些时序仍需真实使用验收。

| 编号 | 用户可见结果 | 验收方式 |

| R01 | 读取本机 Codex 的非归档任务名称、项目和活动状态 | 合成数据库测试、真实任务读取 |
| R02 | 运行、完成、停止、明确等待输入/批准分别呈现；没有证据或活动过旧显示未知 | 状态事件测试、真实数据对照 |

| R05 | 自动加入默认开启；关闭后不再加入；手动排除不会被自动加入覆盖；重启保留偏好 | 核心规则、持久化、真实重启 |
| R06 | 首次只加入活动或等待任务；子任务聚合到主任务；结束后归入完成区 | 合成场景、真实任务 |

| R11 | 可选择 Codex 数据目录、暂停刷新、手动刷新、设置开机启动；设置跨重启保留 | 设置和重启实机验收 |

| R14 | 提供构建、打包、运行、常见问题和限制说明，测试与实际运行证据准确 | 命令检查、文档与产物交叉验收 |
| R15 | 80%/90%/100% 缩放内容与命中区域，重启保留，物理摄像头区不被缩小覆盖 | 几何测试、各比例实机操作 |
| R16 | 圆环常驻、可拖动、悬停/点击展开，共用原关注列表 | 打包应用圆环与展开切换、跨应用悬停 |
| R17 | 拖至顶部释放后进入系统状态栏；普通点击不吸附，窗口不会丢到屏幕外 | 拖动、边界、释放、找回与重启 |
| R18 | 黑/浅玻璃配色可切换；主体轮廓与内容连续过渡，快速进出不会残留窗口 | 实机视觉、动画中断、减少动态效果 |

## 状态证据边界

本机当前 Codex 没有提供可连接的 App Server 控制 socket。第一版以本机只读数据库和 rollout 事件为来源，不声称能读取另一进程未持久化的内存状态。只有明确等待事件才显示待处理；无法识别的批准流程显示已有活动或未知，并引导回到 Codex 查看。未落盘的远程/云任务不冒充本机已接入任务。

配额来自已有日志事件，不请求或缓存认证信息。没有当前配额事件时，显示不可用或历史更新时间。上述限制必须进入用户说明，不能由模拟值掩盖。
