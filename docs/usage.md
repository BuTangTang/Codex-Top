# 使用说明

## 开始

1. 本地构建后双击 `Codex Top Demo.app` 试界面；它只显示示例任务。
2. 实际使用时打开 `Codex Top.app`。在菜单栏找到 Codex Top 图标，选择“显示任务”或“设置…”。
3. 在“选择任务”中搜索任务名或项目、勾选目标后确认。“全选当前结果”只影响当前筛选结果；取消不会提交草稿。
4. “自动监控新任务”默认开启。打开后，新建并开始的任务会加入；自己取消关注的任务不会反复自动加入。

## 把界面变小

设置 → 显示比例，可选 80%、90%、100%。再选显示方式：

- “常驻浮窗”：一行一个任务，拖动左上角横线手柄移动。
- “圆环”：只留下 44pt 小圈，悬停或点击后由小圈本体放大为任务窗口；点右上角收起按钮或按 Escape 缩回原位置，拖动圈本体移动。
- “仅状态栏”：只占用系统状态栏，点击菜单 → 显示任务。
- “顶部”：保留刘海附近或普通屏顶部的状态胶囊。

浮窗或圆环靠近屏幕顶部 24pt 范围，拖动后松手即可收进状态栏。重新选“圆环”或“常驻浮窗”可回到桌面；列表和关注任务保持不变。状态栏位置由 macOS 排布。

圆环只有一条细线：运行时蓝色弧线转动，待回答时琥珀色呼吸，出错时红色提示，全部完成时绿色圆环合拢后静止。未知/未运行用灰色。还有任务运行时，新完成任务可短暂显示绿色反馈后恢复蓝色；待处理提示优先。颜色不代表精确完成百分比。

桌面演示包的设置 →“动画预览”可以直接点“运行 / 待回答 / 完成 / 出错”试效果，“恢复示例状态”恢复原来的合成任务。预览状态退出后不会保存。

纯黑与浅色玻璃在设置里切换；展开面板底部也有快捷按钮。圆环/刘海本身保持深色。常驻浮窗移开鼠标不隐藏；顶部和圆环展开面板设计为离开后收起。

## 外接屏

“顶部显示器”可以自动使用系统主显示器，也可固定显示器。断开后回退可用屏幕；“找回窗口”将窗口移回可见区域。物理拔插、合盖及不同缩放组合仍列在待验收记录中。

## 状态与设置

点击真实任务返回 Codex；演示任务只显示说明。无法打开 Codex 时会提示并复制任务 ID。等待/批准仍到 Codex 中处理，监控工具不会替你批准或执行命令。

“暂停刷新”只暂停本工具的读取，不会暂停 Codex 任务。立即刷新可手动获取最新落盘数据。设置文件与演示设置分别保存在应用自己的 Application Support 目录。“备份并恢复默认设置”会先保存一份备份。

没有任务时先检查数据目录；较久没有活动会显示未知。额度没有记录时显示不可用，不填演示百分比。开机启动需在实际应用中设置，演示包禁用；系统权限提示需要在 Mac 上处理。

如果开启“登录 Mac 时启动”后显示“等待系统允许”，点击“打开系统登录项设置”并在系统中允许；返回应用后会重新读取结果。等待允许不代表已经生效。

当前本地构建包只有 ad-hoc 签名，未提供公证发布版。若下载后的应用被系统阻止，请先核实来源，再按 [Apple 的打开应用说明](https://support.apple.com/zh-cn/102445) 处理。不要为此关闭系统全局保护。
