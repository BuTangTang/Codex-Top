# 使用说明

圆环中心数字是关注列表中正在运行的任务数，超过 99 显示 `99+`。蓝弧表示运行，琥珀表示需要回答或确认，红色表示出错；需要处理时整个圆球轻微缩放呼吸，提醒优先于运行颜色，中心仍保留运行数量。全部完成显示绿色对勾，空闲显示 `0`。点击圆环查看具体事项。

## 开始

1. 实际使用请双击 `Codex Top.app`。如果之前打开的是 `Codex Top Demo.app`，先从其右键菜单退出；Demo 只显示示例任务，不读取真实账户额度。
2. 在菜单栏找到 Codex Top 图标，左键直接显示任务；右键打开菜单后可选择“设置…”。
3. 在“选择任务”中搜索任务名或项目、勾选目标后确认。“全选当前结果”只影响当前筛选结果；取消不会提交草稿。
4. “自动监控新任务”默认开启。打开后，新建并开始的任务会加入；自己取消关注的任务不会反复自动加入。

## 把界面变小

设置 → 显示比例，可选 80%、90%、100%。再选显示方式：

- “常驻浮窗”：一行一个任务，拖动左上角横线手柄移动。
- “圆环”：只留下 44pt 小圈，悬停只有轻微动效，左键点击才由小圈本体放大为任务窗口；展开后移开鼠标仍保留。点击面板外、点右上角收起按钮或按 Escape 缩回原位置，也可切换显示模式；拖动圈本体移动，右键打开与状态栏相同的菜单。
- “仅状态栏”：透明背景显示彩色状态点与计数，数字跟随系统菜单栏明暗；左键在按钮下方展开完整任务面板，再次左键收回，右键打开菜单。展开后鼠标留在状态按钮上或移开都不会自动收起。
- “顶部”：保留刘海附近或普通屏顶部的状态胶囊。

常驻浮窗靠近屏幕顶部 24pt 范围，拖动后松手即可收进状态栏。圆环拖到顶部仍留在桌面，不自动吸附；需要收进状态栏时，右键圆环并选择“仅状态栏”。重新选“圆环”或“常驻浮窗”可回到桌面；列表和关注任务保持不变。状态栏位置由 macOS 排布。

圆环面板展开时，点击外面的桌面或其他应用会让它缩回，同时原来的点击照常生效。单纯移开鼠标不会收起；常驻浮窗也不会因为外部点击而隐藏。

圆环只有一条状态细线：正常运行时仅蓝色弧线转动；待回答或出错时，整个圆球从 44pt 轻微缩至约 41.4pt，再恢复，约 1.8 秒一轮。展开任务面板、处理完事项或开启系统“减少动态效果”后停止呼吸。全部完成时绿色圆环合拢后静止，未知/未运行用灰色。还有任务运行时，新完成任务可短暂显示绿色反馈后恢复蓝色；待处理提示优先。颜色不代表精确完成百分比。

桌面演示包的设置 →“动画预览”可以直接点“运行 / 待回答 / 完成 / 出错”试效果，“恢复示例状态”恢复原来的合成任务。预览状态退出后不会保存。

纯黑与浅色玻璃在设置里切换；展开面板底部也有一键切换按钮。新主题从按下的位置向外圆形扩散，底色、文字与控件一起揭开，其他窗口和圆环同步采用黑白外观。系统开启“减少动态效果”时使用短淡变。刘海摄像头区域与收起的顶部胶囊保持深色。常驻浮窗与点击展开的圆环面板都不会因鼠标移开而隐藏；顶部模式仍在悬停时展开、离开后收起。

浅色玻璃应模糊窗口后面的内容，任务名、搜索框和按钮文字保持清楚。针对“选择任务”后方文字清晰透出的情况，本轮增强了背景材质；实际模糊效果仍待实机确认。

系统状态栏的计数使用原生透明背景，不加黑色胶囊；文字随系统明暗变化，彩色状态点保留，不跟随桌面面板的黑白主题。

状态栏展开面板也跟随 80%、90%、100% 显示比例，窗口、文字和点击区域同步缩放；收回后只保留系统状态栏计数，不应留下小黑块。本轮 D-31 修复已通过 48 项测试及 universal 构建，最终包的状态栏开合、连续点击和各比例显示仍待实机验证。

## 外接屏

“顶部显示器”可以自动使用系统主显示器，也可固定显示器。断开后回退可用屏幕；“找回窗口”将窗口移回可见区域。物理拔插、合盖及不同缩放组合仍列在待验收记录中。

## 状态与设置

点击真实任务返回 Codex 中对应的对话；演示任务只显示说明。无法打开 Codex 时会提示并复制任务 ID。等待/批准仍到 Codex 中处理，监控工具不会替你批准或执行命令。

点击面板底部额度可打开 [Codex 官方用量网页](https://chatgpt.com/codex/settings/usage)。鼠标停在额度上可看来源、更新时间和重置时间；右键额度或进入设置可手动刷新。真实应用通过已登录的 Codex CLI 读取账户额度，自动刷新间隔 60 秒、手动最短 5 秒，单次超过 15 秒会提示超时或暂时无法更新。只显示服务实际返回的窗口：只有周额度时不会补造 5 小时额度。旧记录会提示历史或待更新。

“暂停刷新”阻止新的自动任务扫描和额度请求，不会暂停 Codex 任务；已经发出的读取可以完成。立即刷新可手动获取最新落盘数据和账户额度。设置文件与演示设置分别保存在应用自己的 Application Support 目录。“备份并恢复默认设置”会先保存一份备份。

没有任务时先检查数据目录；较久没有活动会显示未知。额度不可用时检查所选 Codex 目录、Codex 登录状态和网络，也可直接打开官方用量网页；本工具不要求填写或复制 token。额度没有记录时显示不可用，不填演示百分比。开机启动需在实际应用中设置，演示包禁用；系统权限提示需要在 Mac 上处理。

如果开启“登录 Mac 时启动”后显示“等待系统允许”，点击“打开系统登录项设置”并在系统中允许；返回应用后会重新读取结果。等待允许不代表已经生效。

当前本地构建包只有 ad-hoc 签名，未提供公证发布版。若下载后的应用被系统阻止，请先核实来源，再按 [Apple 的打开应用说明](https://support.apple.com/zh-cn/102445) 处理。不要为此关闭系统全局保护。
