# 设计概念

以下是方案阶段的 AI 生成概念图，里面的任务、状态和额度均为示例，不能作为软件已经实现的证据。实际界面以应用截图和验收记录为准。

- `main.png`：顶部、展开与浮窗共用同一列表。
- `picker.png`：已有任务的搜索与多选。
- `automatic.png`：新建任务自动加入。
- `desktop-compact-v1.png`：常驻小浮窗、80% 显示与拖向状态栏的概念候选。

常驻图使用内置 imagegen 生成。生成要求摘要：macOS 桌面里呈现真正小的纯黑三任务浮窗，另给 80% 细节放大、80/90/100 比例选择，以及拖往状态栏的示意；系统字体、克制留白、细分隔线，明确标注示例任务。此处是生成要求摘要，不是完整原始 prompt。

用户随后增加了仅圆环形态；圆环以实际应用实现和验收记录为准。背景/字体的新决定见[参考项目](参考项目.md)。

设计核心：紧凑行式界面；顶部图钉控制显示模式；历史选择和新任务自动加入分别解决已有任务与后续任务。
