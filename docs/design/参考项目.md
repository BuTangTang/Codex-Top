## 对本项目的直接启发

1. 优先解决刘海本体与面板之间的连续变化；内容、轮廓、尺寸和阴影使用一致的过渡时序。
2. 按用户最新决定采用纯黑深色和可选浅色玻璃；透明度不能靠整体窗口 alpha 调整，否则文字也会变淡。
3. 紧凑任务列表不扩展为 Atoll 的音乐/天气/系统监控功能。
4. 外接无刘海屏保持可用，真实交互与动画必须在新打包版本验证。
5. 保留 SwiftUI + AppKit 与现有只读 Codex 数据层。状态条/展开卡片已合为同一窗口，SwiftUI 驱动外壳尺寸与内容过渡；不再用逐帧 AppKit 窗口 resize。没有复制 Atoll 的私有玻璃实现。
