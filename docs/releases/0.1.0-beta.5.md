# Codex Top v0.1.0-beta.5

本版改善回复后的状态更新、运行计时和小字号提示。点图钉后只保留常驻浮窗，顶部刘海隐藏；取消图钉时恢复刘海。找回窗口和后续刷新也遵守同一规则，状态栏入口保留。

- 已关注的待处理任务及其子任务在本地记录变化后触发刷新，合并短时间内的连续事件，保留原来的定期扫描作为兜底。补充识别用户回复记录，收到回复后解除等待。
- `⌘+`（也支持 `⌘=`）放大、`⌘-` 缩小，每次 5%，范围 60%–120%。应用或监控窗口取得键盘焦点时生效。
- 正在运行但缺少可靠开始记录时，先显示 `--:--`，悬停说明原因；仅为已关注主任务及子任务有界回查明确开始记录，兼容后补时间。不会用文件修改或任务创建时间估算，也不回写历史状态。
- “运行中”文字改为主题主文字色，蓝色留给旋转环；待处理、完成和失败颜色及字号不变。
- 运行圈共享 1.2 秒旋转相位，可见前端对齐，新增或重新显示时接入当前节奏；不可见停止，减少动态效果时静止。

110 项测试、通用构建、严格签名和 DMG 只读挂载通过。真实应用的三个计时已恢复并持续增长，深浅文字与圆环同步已检查；详细范围见 [beta.5 验收](../validation/beta5.md)。

中英文 README 与 Windows 开发提示词已同步。支持 macOS 14+，提供 Apple Silicon / Intel 通用 DMG。测试包使用 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证。Windows 文件为开发交接提示词，Windows 软件尚未实现。
