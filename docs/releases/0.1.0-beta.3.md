# Codex Top v0.1.0-beta.3

本版修复切换主题时刘海面板两上角提前变色：旧主题快照现在匹配面板实际轮廓，上角跟随点击位置发出的扩散；浮窗、选择器和菜单栏弹层的圆角同步显示比例。

README 已整理为中文默认入口与英文版，并加入 beta.3 实际刘海窗口的浅深截图；所有公开截图均使用独立测试副本的示例任务。Windows 开发提示词同步确认的交互、数据、计时、测试和交付要求；本版不包含 Windows 应用。

92 项测试、Apple Silicon / Intel 通用构建、严格签名和 DMG 只读挂载检查通过。实际操作内置刘海屏 75% 的双向主题切换及常驻浮窗浅深切换；已更新桌面真实应用。完整动画时间线、所有比例与物理屏幕组合仍有待验范围，见 [beta.3 验收](../validation/beta3.md)。

支持 macOS 14+。真实任务依赖本机 Codex 记录，当前账户额度依赖已登录的官方 Codex CLI。安装包为 ad-hoc 签名，未 Developer ID 签名或 Apple 公证。
