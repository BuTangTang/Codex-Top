# Codex Top v0.1.0-beta.2

本版为独立测试预览版（Pre-release），保留 beta.1 的历史下载附件。

## 本版调整

- 外接屏使用紧凑字号，内置屏保持常规字号；常驻浮窗无论在哪块屏幕都更紧凑。按每个窗口的实际屏幕判断，暂时无法识别时保持原字号。
- 浅色待处理圆环、任务圆点和面板标签统一橙色，小标签采用 12% 淡橙底配深色文字，圆球仅叠很淡的橙色背景。深色保留原琥珀半透明底，失败仍红；任务状态和提醒优先级不变。
- 显示比例改为 **60%–120% 原生滑块，每 5% 一档**，可连续拖动，显示当前百分比并可恢复 100%。整数百分比与 13 个原生刻度保持同步，避免末档不可达或滑块位置与数值不同步；旧 80%、90%、100% 设置兼容，桌面圆环仍为 44pt。60%–75% 的展开头部用加号打开选择器，为标题和按钮留出空间。
- 待处理标签后显示本轮开始到当前等待开始的固定 `mm:ss`，等回答期间不增长。缺少有效时间就不显示估算；回答/新轮清空，重复等待与普通输出不重置。子任务提升的等待使用该子任务自己的耗时；数值不是 CPU 用时，也不自动扣除本轮更早的等待。

## 验证与使用条件

92 项自动测试、Apple Silicon / Intel 通用构建、严格签名和 DMG 只读挂载校验通过。实际核对 13 档控件值与恢复 100%、60% 小窗口/选择器/待处理时长、80% 双主题和常驻浮窗，README 已补实际应用的示例任务截图。

鼠标连续拖动未取得可靠的工具位移证据，完整顶部拖动、物理拔插/合盖、真实换号和逐帧动画仍有待验范围。截图不代表 FPS 或完全零抖动；详见 [beta.2 验收](../validation/beta2.md)。

支持 **macOS 14+**，提供 **Apple Silicon / Intel 通用 DMG**。真实任务需要本机 Codex 及任务记录，当前账户额度需要已登录且可用的官方 Codex CLI。Developer ID 签名与 Apple 公证尚未提供；不要把包校验通过当作已公证。

使用规则见[使用说明](../usage.md)，Windows 同事可参考[开发提示词](../handoff/windows-implementation-prompts.md)。本版不包含 Windows 实现。
