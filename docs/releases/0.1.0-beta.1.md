# Codex Top v0.1.0-beta.1

首个预发布测试版（Pre-release），适合试用和反馈，尚非稳定版。

## 下载与安装

1. 从本页 **Assets** 下载 `.dmg`，打开后将 **Codex Top.app** 拖到 **Applications（应用程序）**。
2. 从应用程序打开 Codex Top。要求 **macOS 14 或更新版本**，同一个通用包支持 **Apple Silicon 与 Intel**。
3. 真实任务需要本机已有 Codex 及本地任务记录；账户额度需要可用且已登录的官方 Codex CLI。无需向 Codex Top 提供 API Key 或 token。

## 本版内容

- 四种模式共用关注列表：刘海、常驻浮窗、44pt 圆环、仅状态栏。
- 所有拖放取消自动吸附和自动切状态栏；浮窗及展开圆环的整条顶部可直接拖动，按钮除外。移动展开面板后，小球收起到新位置。
- 圆环消失后从原位置沿固定边展开，空间不足时向屏幕内侧调整；开合共用弹簧进度，文字不再额外缩放。
- 待回答/批准及错误有提醒；大段工具输出不再清掉已建立的等待或轮次，展开已结束区时保留运行任务。
- 当前账户额度独立刷新，历史日志单独标注；暂停任务刷新不暂停额度，读取失败不复用旧账号余额。

## 验证与已知限制

**78 项自动测试、arm64/x86_64 universal 构建及严格签名检查通过。** 最新顶部拖动交互尚未完成实机回归；完整动画帧率仍待验证。多屏物理拔插、实际账号切换等边界见[验收记录](https://github.com/BuTangTang/Codex-Top/blob/v0.1.0-beta.1/docs/validation/acceptance-matrix.md)。

此包使用 **ad-hoc 签名**，没有 Developer ID 签名或 Apple 公证，下载后可能被 macOS 拦截。严格签名检查通过不等于已公证；不要关闭系统全局安全保护。

任务状态来自已落盘记录；首次有限尾读可能无法恢复更早的未答问题，大日志追赶期间会显示同步状态。任务与账户数据只读，不上传任务内容。

Windows 版尚未实现，同事可从[完整开发提示词与源码映射](https://github.com/BuTangTang/Codex-Top/blob/v0.1.0-beta.1/docs/handoff/windows-implementation-prompts.md)开始。
