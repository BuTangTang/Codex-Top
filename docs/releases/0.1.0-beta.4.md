# Codex Top v0.1.0-beta.4

设置窗口现在跟随打开时鼠标所在的屏幕，不再跟随固定的刘海显示器。

- 首次打开、关闭后重开或从另一块屏幕再次进入设置时，在目标屏幕工作区居中，并避开菜单栏和 Dock。
- 设置已经完整显示在鼠标所在屏幕内时，保留你调整过的位置和窗口大小。
- 复用已有设置窗口，保留内容与滚动位置；首次窗口尺寸也按目标屏幕计算。

中英文 README、使用说明和 Windows 开发提示词已同步。具体构建、实际窗口与分发校验见 [beta.4 验收](../validation/beta4.md)；其他功能与历史截图来源不变。

支持 macOS 14+，提供 Apple Silicon / Intel 通用 DMG。真实任务需要本机 Codex 记录，额度需要已登录的官方 Codex CLI。测试包为 ad-hoc 签名，未 Developer ID 签名或 Apple 公证。


92 项测试、通用构建和镜像校验通过；设置打开/再次进入已实际操作，完整主副屏往返位置仍按验收记录保留未验边界。桌面真实应用已更新，只保留一个监控实例。
