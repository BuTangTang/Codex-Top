# M1 内容整理（约 1 天）

目标：设计第 3、5、6 节——三份内容和口令判断，做成不依赖界面的纯整理，全部用合成数据测。

- [x] T1.1 设置文件加三项：允许局域网设备读取（默认关）、口令、给任务标题（默认开）。都是可选项，旧设置文件照常读入。
- [x] T1.2 三份内容的格式按设计附录 A 定下来，格式版本 1，时间一律秒级时间戳，没有就是空。
- [x] T1.3 总览：整体状态（失败／等待／在跑／空闲／未知／读取中／已暂停，和悬浮球同一套判断）；个数：在跑、等你处理、失败、刚完成、关注中未结束、已结束（只给个数，D-07）；电脑名、生成时间。
- [x] T1.4 任务：顺序“需要你处理 → 刚完成 → 进行中”；最多 20 条，多了标“还有更多”；标题开关和 40 字截断；七种状态；分段；开始时间没有就给空；在等你处理时给等待开始时间。
- [x] T1.5 任务的状态文字：把面板任务行第二行的拼法（含“· N 个子任务”“· 已等 N 分钟”“本轮执行已结束 · N 分钟前”）提成一处，面板和接口共用，保证一字不差；“已等几分钟”按请求时刻算。
- [x] T1.6 用量：Codex 额度各窗口（有 5 小时才给、读不到标出并给最后读到的时间）；Codex、Claude Code 今天的总数和构成、昨天总数、近 7 天每天的总数和起点；写明中午 12 点切天。
- [x] T1.7 口令：6 位数字随机生成、比较；判断请求是否来自本机（本机免口令）。
- [x] T1.8 自动测试：上面每一项各有用例；另查三份内容里找不到路径、正文、账号；标题关掉时一个标题都没有。

结果（2026-11-11）：整理放在 Core，三份内容按附录 A 输出；任务行第二行文字提成一处，面板和接口共用。合成数据测试 8 项全过。
