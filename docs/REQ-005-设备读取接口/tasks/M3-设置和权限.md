# M3 设置和权限（约半天）

目标：设计第 7、8 节——用户能在设置里开关、看口令和地址，系统权限说明到位。

- [x] T3.1 设置窗口“任务”一组后加“设备读取”：允许局域网设备读取（开关）、口令（打开后显示，带“换一个”）、给任务标题（开关）、一行地址或出错原因（“设备可以访问 192.168.x.x:8770”／“端口被占用”／“未能广播”）。
- [x] T3.2 开关切换时服务立刻按新范围重开、广播跟着开关；换口令后旧口令立刻失效；第一次打开开关时自动生成口令。
- [x] T3.3 App 启动时按设置开服务，退出时关。
- [x] T3.4 打包脚本的 App 信息里加本地网络用途说明和服务名，系统弹提示时写清楚是给局域网设备读取状态用的。

结果（2026-11-11）：设置“任务”分类下加“设备读取”一组；演示模式不开接口，免得和真实 App 抢端口。App 信息加了本地网络用途说明和服务名。
