# M2 接口服务（约 1 天）

目标：设计第 2、4、6 节——在电脑上收请求、验口令、回内容，打开局域网时广播。

- [x] T2.1 服务两种范围：开关关着只收本机请求，打开后同时收局域网请求；端口 8770；端口被占用时记下原因给设置显示，App 其他功能照常。
- [x] T2.2 请求处理：只认三个地址的读取请求；地址不对回“找不到”，不是读取回“不允许”，请求头超过 8KB 拒绝；同时最多 8 个连接，5 秒没收完断开，回完就关连接。
- [x] T2.3 口令接入：局域网来的请求必须带对口令，否则“未授权”；同一来源地址连续错 5 次，1 分钟内一律拒绝，过后恢复。
- [x] T2.4 取内容：请求来时在主线程用 M1 的整理从面板结果拼内容，不读磁盘、不触发刷新；在后台发出去。
- [x] T2.5 局域网广播：只在开关打开时广播，服务名 `_codextop._tcp`，显示名用电脑名，附带格式版本和“需要口令”；关掉就停。
- [x] T2.6 自动测试：在本机随机端口起服务，测三个地址回 200 和正确内容、错地址 404、非读取 405、超大请求头被拒；口令用例（没带、带错、换口令后带旧的、连续错 5 次后带对的也被拒）用测试开关模拟“局域网来源”。

结果（2026-11-11）：服务放在主线程，开关关着只听回环地址；请求头分几次到齐时也按整段 8KB 判断（测试抓到过一次）。本机随机端口测试 3 项全过；局域网广播不进自动测试，放在 M4 实测。

v0.3 追加（2026-11-11）：

- [x] T2.7 主题地址只认读取；打开任务地址只认提交，方法不对回“不允许”；局域网来的先验口令再看地址。
- [x] T2.8 打开任务：面板点行用的那段加“成没成”回调（面板行为不变），接口按编号在需要你处理／刚完成／进行中里找，找到就打开并按结果回复，找不到回“找不到”。
- [x] T2.9 自动测试：主题地址、打开任务的提交和方法、找不到、局域网没口令被拒。

v0.3 结果：先过口令再看地址和方法；面板打开任务加了“成没成”回调，面板行为不变；新增测试 1 项并扩充口令用例，共 4 项全过。构建 160。
