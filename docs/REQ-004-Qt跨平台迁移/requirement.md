# REQ-004 迁移到 Qt、实现跨平台：需求

版本：v0.1 **已通过**（2026-11-10，用户：“可以下一步吧”，第 7 节四个问题同日答复，记为 D-07～D-10）。依据[方案讨论稿](方案讨论稿.md)。

## 1. 目标

用一套 Qt 程序出 Mac 和 Windows 两个版本，功能、样子和规则跟现在的 Mac 原生版一致。Qt 版追平后，Mac 也改用 Qt 版，原生版退役，以后只维护一份代码。

## 2. 范围

做：
- Mac（macOS 14 及以上，Apple 芯片和 Intel）和 Windows 11（x64）两个版本。
- 现在 Mac 原生版的桌面监控功能全部搬过去（第 4 节逐项列出）。
- 两个平台各自的入口、开机启动、打包。

不做（这一版）：
- Linux（D-02，以后再加；代码里不写死只认两个平台）。
- 手机连接组件（D-04，继续由 Mac 原生版提供；原生版退役时手机连接暂停，D-08）。
- 新功能：搬迁期间只搬现有功能，不顺手加新的（D-03）。

## 4. 需求

### 技术验证（先做，过了才往下）

- **R-01 先验证再搬**：正式搬迁之前，先只做一个悬浮球：透明、置顶、可拖动，带 LED 点阵和绕圈动画。在 Mac 的 1 倍外接屏、2 倍内置屏和 Windows 11 上实看，并量空闲时的 CPU 和内存。下面三条都达到才进入正式搬迁，否则回来重新讨论方案：
  - 1 倍屏上点阵逐像素清楚，不糊、不变形（同现在原生版的标准）；
  - 点悬浮球、拖动、展开面板时不抢走其他程序的输入焦点，不挡全屏程序；
  - 静止时（没有任务在跑、面板收起）不重绘，CPU 接近 0；有动画时占用和原生版同一个量级。

### 数据（和原生版结果一致）

- **R-02 读 Codex**：读 Codex 的状态库、任务记录和压缩记录，规则和原生版相同；只读，不改 Codex 的任何文件。
- **R-03 读 Claude Code**：读 Claude Code 的会话记录、运行登记和钩子事件，规则和原生版相同。
- **R-04 状态与计时**：七种状态、“刚完成”、计时、缺开始时间显示 `--:--` 等规则全部照搬。
- **R-05 关注规则**：自动关注、手动移出优先、按天数自动移出已结束任务、子任务归到主任务，照搬。
- **R-06 额度与用量**：Codex 账户额度（有几个窗口显示几个）、Claude 和 Codex 的近 7 天用量统计，照搬。
- **R-07 结果对齐**：原生版现有测试里的合成样例全部拿来，Qt 版对同一批样例算出的结果必须和原生版一样，才算这部分搬完。测试只用合成样例和临时目录，不读真实数据。

### 界面（样子和操作照原生版）

- **R-08 悬浮球**：LED 点阵、彗星绕圈、做完／等你／失败时变色跑两圈、全部完成 OK 和休眠 Zz、刚完成的绿色个数、贴边停放、拖动。
- **R-09 展开面板**：分段（需要你处理、刚完成、进行中、已结束）、行首竖条灯、等宽计时、等你／失败标签、来源标记 CX／CC、可见行数、滚动规则。
- **R-10 底栏和用量卡片**：已结束折叠、CX 额度、CC 今天用量，点开对应的用量卡片，同时只开一张，面板收起时自动收起。
- **R-11 任务选择器**：搜索、多选、加入或移出关注。
- **R-12 设置**：显示方式、配色（深色／浅色／跟随系统）、缩放、可见任务数、自动监控、自动移出天数、暂停刷新、开机启动、Codex 和 Claude Code 数据目录、Claude Code 开关、“显示等待你批准”的钩子开关。
- **R-13 点击任务**：打开 Codex 或 Claude 桌面 App 并尽量定位到这个任务；打不开时如实提示，不假装成功。
- **R-14 清晰度**：两个平台、1 倍和 2 倍屏（Windows 还有 125%／150% 这类缩放）上，点阵和细线都对齐像素、不糊。
- **R-15 减少动态效果**：系统开了“减少动态效果”时，和原生版一样不放动画。

### 各平台不同的部分

- **R-16 显示方式**：两个平台都有悬浮球、常驻浮窗、屏幕顶部。Mac 另有刘海模式和菜单栏入口；Windows 用右下角托盘图标代替菜单栏入口，没有刘海模式。
- **R-17 开机启动**：Mac 用系统登录项，Windows 用当前用户的启动项；都可以在设置里开关。
- **R-18 Claude Code 钩子**：Windows 也提供“显示等待你批准”，用 Windows 版的小程序和命令写法；只改自己那一条、改前备份、关掉就删干净，规则同原生版。
- **R-19 数据目录**：两个平台默认都是用户目录下的 `.codex` 和 `.claude`，也支持它们各自的环境变量和手动选择。

### 资源、打包和隐私

- **R-20 资源占用**：常驻时 CPU 和内存不高于原生版现有水平；具体数值在设计里按原生版最新的测量结果定。
- **R-21 安装包**：Mac 出签名的 App（可做成 dmg），Windows 出安装包或免安装压缩包，都自带 Qt 运行库，用户不用另外安装。
- **R-22 隐私**：和原生版一样：不记录对话正文、密钥和完整本机路径，不上传任何内容。

### 切换

- **R-23 并行试用**：Qt 版在你的 Mac（两块屏）和远程那台 Windows 11（D-09）上并行用一段时间，期间原生版保留可用。
- **R-25 导入原生版设置**：Mac 上第一次启动 Qt 版时，自动导入原生版的关注列表和设置（D-07）；只读原生版的设置文件，原生版不受影响；导入失败时从默认设置开始并提示一次。
- **R-24 切换条件**：第 4 节需求都验收通过、并行试用期间没有原生版有而 Qt 版缺的功能，原生版才退役；退役时手机连接随之暂停（D-08），切换前提醒用户。

## 5. 验收要求

- 技术验证（R-01）单独出一份记录：截图、逐像素核对、焦点和全屏的实测、空闲和动画时的 CPU／内存数据。
- 数据层：原生版合成样例在 Qt 版全部通过；新写的测试同样只用合成数据。
- 界面：两个平台的打包版在真实窗口里逐项核对 R-08～R-16，Mac 要两块屏都看；截图和原生版并排对比。
- 钩子、开机启动：开关后回读文件或系统设置，确认装上、删干净。
- 资源：和原生版在同样条件下各量一次。

## 6. 不确定、需要验证的

- Windows 版 Codex 桌面 App、Claude 桌面 App 是否认现在 Mac 上用的那种打开链接（影响 R-13），技术验证时一起确认。
- Windows 上 Codex 的状态库位置和格式是否与 Mac 相同（`windows` 分支的经验是相同，需再核对）。
- Qt 透明置顶小窗在 Windows 多屏、不同缩放下的表现（R-01 验证）。
