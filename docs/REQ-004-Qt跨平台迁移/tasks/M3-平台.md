# M3 平台（约 2 周）

目标：设计第 6～8 节——两个平台各自的部分、导入设置、打包。

- [ ] T3.1 Mac：刘海位置、菜单栏图标和弹出面板、登录项开机启动。
- [ ] T3.2 Windows：托盘图标和弹出面板、启动项开机启动、多屏不同缩放。
- [ ] T3.3 钩子小程序：Mac、Windows 各编一份；Windows 的命令写法；远程 Windows 上实测一次批准提示。
- [ ] T3.4 导入原生版设置（R-25）：只读、认得的字段照抄、失败提示一次；原生版装的钩子条目被认出并换成 Qt 版路径。
- [ ] T3.5 Mac 打包：运行库进 App、签名、dmg；应用标识加 `.qt`，能和原生版同时装。
- [ ] T3.6 Windows 打包：免安装压缩包（可选安装程序）。
- [ ] T3.7 两个平台的打包版安装后实看 R-08～R-16，钩子和开机启动开关后回读；资源与原生版同条件对比；写验收记录。
