- [ ] 发布窗口内只操作 `/opt/codex-top` 对应项目；部署前后核对 PVTC 健康、端口与资源。
- [ ] 汇总各验收项的实际通过／失败／未运行，单独记录能力限制；任何必需闭环失败不标整体完成。
- [ ] 整理给用户的安装、登录、通知权限和故障说明，步骤附脱敏实机图；不暴露开发实现细节。
- [ ] 代码修复回原任务、修复后仅重跑受影响场景；收回所有写权再更新总状态。
- [ ] 如进入提交发布阶段，遵守项目检查及既有授权，只提交本项目已审核范围，不强推、不混入构建和凭据。

## 7. 停止与失败处理

误入真实工作任务、目标身份不一致、串账号、重复执行、敏感材料泄露或 PVTC 异常时立即停止相关动作，保存最少必要证据交主管处理。
部署出错只撤回本项目，不能重启、改库或删除 PVTC 资源；数据回退以兼容性和备份验证为前提。
结束时明确安装了哪个版本、哪些链路通过、哪些未完成；“完成 tasks 文档”“构建成功”“安装成功”均不能替代产品验收。
