目标：真实任务事件送达小米，通知进入正确对话；自建服务独立部署且保护 PVTC。

## 1. 依赖与交接

- M1 提供账号身份、登录代次、退出与换号结果；M4 不修改认证、开户或密码逻辑。
- M2 提供真实事件、电脑及原任务映射、有效审批请求标识；状态回声不能当新事件。
- M3 提供对话导航及通知设置展示契约；M4 独占通知响应到目标导航的逻辑，不另造页面。
- 未登录目标恢复：M4 暂存无正文目标，M1 登录结果触发校验，M3 展示正确对话或不可访问原因。
- 换号交接：M1 发出账号切换边界，M4 解除旧推送归属、清理旧通知及待处理目标，M3 清空旧展示。
- 开始产品工作前，主管确认需求、设计、任务版本和实施指令；本轮任务文档不授予实施权限。
- 设备与生产窗口由主管统一安排；未取得窗口不得并行操作手机、桌面、SSH 或生产服务。

## 4. 通知工作与验收

- [ ] 复用真实完成／待处理／异常事件，以账号、电脑、原任务和事件身份去重，不限制历史浏览范围。
- [ ] 区分首次同步、重连补齐和新事件；过期审批不继续提示仍需处理，重复投递不重复骚扰。
- [ ] 沿用 `POST /v1/push-tokens`、`GET /v1/push-tokens`、`DELETE /v1/push-tokens/:token`；不为页面另造端点。
- [ ] 校验推送 token 的设备与账号归属；退出、换号、失效 token 的清理结果可辨认，离线注销不谎称完成。
- [ ] 默认载荷只含必要定位和状态，不上传完整正文、命令或凭据；跳转前重新核验当前账号可访问性。
- [ ] 通知直达指定电脑的原会话；未登录保留受限目标，同账号登录恢复，换账号不消费旧目标。
- [ ] 冷启动、前台、后台、重复点击、切服换号与迟到回调不串线、不叠页；断网保留定位并如实提示。
- [ ] 有待处理请求时进入对话内详情；不得让旧通知按钮绕过详情或重放允许／拒绝，审批提交交 M2。
- [ ] 先验证现有 Expo 通道；不可用时提交厂商推送适配证据和选择，不自行用无限轮询替代。
- [ ] 新增或修改的方法写中文注释；目标校验、去重、退出及重试的关键步骤解释原因，部署说明写明前提、结果和失败处理。
- [ ] 使用两个合成账号、两台电脑同名任务验证隔离、去重、失效和正确跳转。
- [ ] 由主管在小米验证前台、后台、锁屏、系统回收及跨网送达；分别记录服务接收、下游 receipt、手机展示和点击定位。

## 5. 云端工作与验收

- [ ] 在隔离环境构建对应源码镜像，记录版本；构建上下文排除本地账号、数据、日志和诊断材料。
- [ ] 配置 `/opt/codex-top` 独立 Compose project、网络、数据卷、数据库、密钥和备份；不连接 PVTC 资源。
- [ ] 应用非 root 运行，容器复用 3005；宿主端口经检查后仅绑定回环，通过独立 HTTPS 入口访问。
- [ ] 配置 CPU、内存、进程、日志轮转及数据／备份保留限制；具体值依据资源基线，不预填未经核验的生产值。
- [ ] 持久化数据库、文件及服务主密钥；限制文件权限，建立一致性备份并在隔离环境实际恢复。
- [ ] 验证 HTTPS、实时长连接、跨网重连、账号隔离、通知注册和健康／就绪，不把单个 HTTP 200 当端到端通过。
- [ ] 先演练本项目升级与回退；明确数据库兼容条件，不能只退镜像却忽略数据库格式变化。
- [ ] 主管安排窗口后执行发布；前后只读对照 PVTC 健康、资源和端口，异常仅停止或撤回本项目。
- [ ] 提供安装、备份恢复、升级撤回和故障核对说明；秘密通过受控渠道交付，不进入文档或仓库。

## 6. 停止条件与交付判定

- 推送渠道未验证、真实目标无法映射、换号隔离未通过：停止宣称通知闭环完成，保留证据交主管。
- 域名／证书／入口不明、备份恢复失败、资源不足或 PVTC 异常：停止生产发布，不改用共享数据库或无限额部署。
- 需要修改其他模块 owner 或扩大生产权限时，先交接写权和范围，不并行抢写或擅自执行。
- 完成须具备账号隔离、真实送达、正确跳转、公网链路及 PVTC 前后对照证据；静态测试、构建和安装分别记录，不能互相替代。
