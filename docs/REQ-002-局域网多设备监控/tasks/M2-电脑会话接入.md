# M2 电脑会话接入

状态：进行中。原任务控制和真实项目读取已接线；本批原生新建按 D-05 后续待对接，手机入口关闭。
依据：[需求](../requirement.md) v0.10、[详细设计](../detailed-design.md) v0.2；实施前核对主管记录的审核版本及实施指令。

## 目标与边界

让手机访问自己账号下所选电脑的全部可访问 Codex 历史，选择真实项目创建 Desktop 原生任务，并在桌面 Codex 持续开启时继续原任务、接收回复及处理审批。
支持多台电脑；关注只控制通知，不成为历史浏览或会话操作的前提。
必须保留真实目标身份和 Desktop 执行权，不能以接管、resume、新 runner 或普通机器 spawn 冒充原生新建及同任务操作。
不修改 Codex 数据库、配置、记录或认证文件；不实施账号界面、手机页面、推送或服务器部署。
不预设公开端点，也不把当前 Codex 对话工具视为可嵌入 SDK；Windows 和忙时追加仍须核验，不能默认为已支持。

## 依赖与唯一写权

- M1 交付账号、电脑绑定及访问隔离契约后，才能接入实际认证和授权；独立账号不得共享本机来源或缓存。
- M2 单一 owner 持有本模块涉及的 protocol DirectSession 类型、RPC 定义、CLI provider、Desktop 适配器和相应测试写权。
- M1 若需改同一协议导出文件，先由主管分批分配；禁止两个任务并行修改共享协议或生成产物。
- M3 只在 M2 交回经验证的能力、数据和错误契约后接手机界面；界面不能根据示例或按钮存在推断能力。
- 真实设备、桌面实例、测试任务发送及审批由主管统一安排；本任务不并行控制设备或启动服务。

以下为拟复用 owner，不是本轮修改清单；开工前核对真实路径，新增文件先报主管。

## 工作顺序

- [ ] 核对需求、设计审核记录及实施授权；取得本批唯一文件写权。
- [ ] 只读记录目标 Desktop 版本、平台、已有通信入口、协议版本及 owner 发现条件。
- [ ] 核对历史来源是否覆盖未关注、归档、不同项目及分页；明确不可访问与查询不完整的区别。
- [ ] 核验所选电脑真实项目来源、项目标识及可用性，不能用最近工作目录冒称完整项目列表。
- [ ] 核验原生任务创建入口及实际返回身份；要求 Desktop 内能确认存在，不接受只生成手机占位项。
- [ ] 核验空闲发送、运行中追加及桌面同时操作的实际语义，区分接受、排队、拒绝和未知结果。
- [ ] 核验审批详情读取、确认、拒绝及真实处理回执；区分权限审批与需要用户回答的问题。
- [ ] 核验 Windows 通信与权限边界；当前 Unix socket 实现的拒绝行为不能作为 Windows 已交付证据。
- [ ] 将上述核验结果交主管；任一必要入口不可用即登记阻断、影响和可选路线，不静默删除目标。
- [ ] 在真实入口证据上冻结最小逻辑契约及适配范围，再由主管安排依赖实现。
- [ ] 固定目标元组：服务、账号、电脑、Codex 来源、原任务；创建还绑定真实项目，审批绑定 turn/request。
- [ ] 复用现有分页、关联及正文 owner，历史浏览独立于关注状态，覆盖来源变更与游标失效。
- [ ] 复用现有稳定 localId、意图及回执机制；结果未知不自动改 ID 重投，不宣称 exactly-once。
- [ ] 接入原生创建与审批已核验入口，校验 owner/目标/请求仍有效，禁止跨任务、重复或过期决定。
- [ ] 增补版本能力门禁与断线处理；不兼容、无 owner、未观察、离线分别表达，不虚报成功。
- [ ] 有意义的行为变更先 RED 再 GREEN；完成对应协议/CLI 检查后交回契约、差异及写权给主管。

## 验收清单（全部待执行）

- [ ] 未关注任务仍可检索并读正文；真实历史覆盖与分页边界有证据，无法覆盖时明确不完整。
- [ ] 项目来自所选电脑；创建后核对 Desktop 原任务身份、首条消息、回复及继续发送能力。
- [ ] Desktop 保持开启，手机发送进入同一原任务；桌面后续输入和回复仍可在手机正确呈现。
- [ ] 运行中追加及桌面并发输入按已验证策略处理；不丢消息、不重复启动、不把未知当接受。
- [ ] 对同一测试任务分别确认和拒绝审批，核对 Desktop 实际处理；已处理、过期及错目标请求不误执行。
- [ ] 两台电脑同名项目、同名任务不串线；切换列表电脑不改变已打开对话的发送目标。
- [ ] 两账号分别验证历史、项目、正文、发送、创建与审批隔离；伪造另一账号目标同样拒绝。
- [ ] 断线、owner 变更、协议不兼容和回执丢失均明确展示；重连不重放已提交的不确定操作。
- [ ] Windows 若属于实际交付电脑，取得对应真实版本证据；未通过则作为阻断交主管处理。
- [ ] 主管用正式包连续验证并归档版本、目标身份、结果及限制；不以合成 router 测试替代真机证明。
