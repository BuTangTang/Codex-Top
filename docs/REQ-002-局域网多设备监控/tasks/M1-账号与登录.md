# M1 账号与登录

状态：进行中。用户已授权实施；协议、CLI 和手机登录已接线，主管正在实际两端联调。正式同事账号尚未创建。
基线：[需求 v0.10](../requirement.md)（D-04）、[详细设计 v0.2](../detailed-design.md)第 4、8、10 节。
负责人：账号实施任务与主管；源码、专项测试、设备验收分别记录，不以专项通过代替端到端通过。

## 1. 目标与排除

管理员预建一个独立同事账号及密码；手机和原生 Mac 使用同一账号直接登录、记住登录并退出当前端。
服务端原 Account 是唯一产品身份；账号凭据与实际解密材料一致后才进入已登录态。
用户与同事的电脑、项目、会话及通知隔离；保留已有账号、历史和密钥，不自动迁移、覆盖或共享。
候选加密兼容逻辑作为内部实现核对，不增加用户密钥操作步骤，也不宣称协议已审计或属于 OPAQUE。
可信管理员预建过程中可能接触初始材料；不新增“管理员不可接触”或服务端托管恢复密钥承诺。
不做首次激活、公众注册、自助改密、找回密码、恢复码、设备管理或一键踢出其他端。
退出当前端不代表撤销所有设备，也不承诺收回其他端已经保存的内容或密钥。

## 2. 依赖和交接

- 开工前确认上述需求、设计和本任务范围一致，并取得用户实施指令。
- 先核对现有未发布候选代码与专项失败记录，不能将文件存在或历史测试当作本批通过。
- 服务端参数与登录契约稳定后接手机及 Mac；协议变更由一个 owner 统一，不由两端分别实现。
- Mac 登录接线依赖本机连接组件的生命周期和账号绑定边界，与电脑接入任务协调。
- 登录、错误、记住登录、退出先由 M1 完成功能接线；通知只提供登录完成／退出边界，目标保存与消费由 M4 独占，纯外观随后交 M3。
- 共享 `Sources/CodexTop/Views.swift` 按批独占写入；M1 交回前 M3 不并写。
- 部署、正式账号创建及真实设备验收由主管另行安排，本文件不提前执行。

## 4. 执行清单

- [ ] 核对现有协议、路由、预建脚本、手机候选及 Mac 缺口，列出保留／修复项和精确写权。
- [ ] 用合成账号补决定性 RED：错密、错误封套／账号替换、切服及失焦后迟到结果不得登录。
- [ ] 修正服务端参数及登录链路，验证登录资格、限流、统一错误和敏感信息不进入日志。
- [ ] 验证预建过程独立创建 Account 与凭据，重复账号失败且不覆盖旧账号；失败无半成品。
- [ ] 核对安全传输和共享派生／封套校验；真实登录同时恢复正确账号密钥，不能只验 token。
- [ ] 手机接入原认证 owner，密码显示切换、错误保留输入、重复提交抑制和服务器入口可操作。
- [ ] 验证记住登录：重启从本端原安全存储恢复；不保存输入密码，不把明文表单写入普通偏好。
- [ ] 对网络、派生及保存的异步边界检查服务器身份和请求代次；换服或离开页面不误激活旧结果。
- [ ] Mac 原生表单接统一 CLI 认证 owner，限制本机调用用户，按账号绑定电脑连接并呈现真实状态。
- [ ] 实现退出当前端：停止旧连接与待提交动作、清理本端凭据和旧账号展示，处理该端推送归属。
- [ ] 退出遇网络失败仍能清除本端登录；不显示全设备撤销成功，其他已登录端按原范围继续工作。
- [ ] 验证账号切换不复用前账号缓存、草稿、通知目标、机器连接或迟到回调；旧账号服务端历史与身份仍保留。
- [ ] 登录完成后调用 M4 的通知恢复 owner，由其校验原来源与账号；不在认证层另建 pending 记录，另一账号不得读取或打开旧目标。
- [ ] 双账号核验电脑、项目、历史读取及操作归属；共享数据源无可信隔离边界时拒绝接入。
- [ ] 每个新增或修改的方法写中文用途注释，重要加密、存储、取消与连接交接步骤补中文说明。
- [ ] 完成 GREEN、相邻回归及对应类型／构建检查，再交主管组织两端真实连续操作验收。
- [ ] 将功能接线、稳定状态与精确文件交 M3 做外观收口；记录完成、未验证和停止项，不代勾其他任务。

- [ ] 退出一端后另一端行为、离线退出、A→B 换号和旧请求迟到的连续操作记录。
- [ ] 两账号直接使用对方目标标识仍被拒绝；历史正文、发送、审批及推送跨任务集成由主管统一验收。
- [ ] Mac 服务失效不影响本机只读监控；手机真实 KDF 耗时、忙态及键盘操作留证，不以静态图证明流畅。
- [ ] 专项命令、退出码、未通过原因和未运行门槛分别记录；测试、构建、安装和公网验收不互相替代。

## 6. 停止条件与交还

- 候选协议无法证明账号与解密材料绑定，或统一认证 owner 不可复用：停相应接线，交主管收敛方案。
- 需要覆盖旧账号、迁移旧密钥、增加账号生命周期功能或改变管理员信任范围：先交用户确认，不自行扩展。
- 共享系统用户／数据源无法建立隔离，或异步保存会串账号：拒绝该路径，不能靠隐藏列表规避。
- 遇同文件写权冲突、真实凭据读取或生产开户／服务操作需求：停止该动作，交主管协调。
- 完成后交还精确文件、差异摘要、测试与真实验收证据、残余风险；主管统一更新进度，不擅自发布。
