## 审查与验证

主管复跑首版16项本地检查通过。独立审查发现两项 P2，已由原部署任务修复：

1. 容器停止后的检查失败不能绕过备份失败恢复；恢复前必须重新核对原实例身份与状态。
2. Compose 渲染的 CPU、内存/交换、PIDs 必须与归档所记录配置一致，不能通过改写 Compose 突破已审核预算。

这些检查使用真实 Compose 静态解析、临时合成 SQLite 和归档。Docker 状态及 age 外部调用使用替代实现，未连接 Docker daemon、未执行真实加密、未访问远端。
