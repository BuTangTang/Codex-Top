## Tab 建议

用户指的是输入框按 Tab 接受的 composer prediction。当前桌面将建议缓存在内存，普通历史与 follower IPC 没有建议读取方法，相关 DOM 隐藏于辅助功能。手机同步尚未实现；不使用重新推理或定时 OCR 冒充同步。预期行为为点击后只填入草稿，由用户发送，来源回合变化时失效。
