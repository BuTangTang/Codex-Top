## 剩余验收所需条件

- 圆环保留点击展开/外部点击收回，顶部仍悬停；已补真实任务/额度前景、80% 完整面板与关闭隐藏，优先补系统图标左/右键与其余比例。初次窗口获取及后续浏览器查询超时不算通过；调试服务已退出。遵守单会话，当前接口没有独立 hover 或逐帧录像，端点截图不能代替完整动画。
- 可操作的物理屏幕与现场操作：内置刘海、拔插/合盖、重新连接及各比例。几何测试不能代替。
- 系统开机启动与减少动态效果需要实际系统设置流程；未自动接受权限、未替用户修改这些系统设置。
- 真实任务跳转终点受当前 CUA 对 Codex 应用的访问限制；不绕过。
- CI 授权、Developer ID、Apple 公证和正式 Release 属于分发/运维边界，分别记录，不能伪造已交付。
