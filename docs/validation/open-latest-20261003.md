用户要求见[D-44](../REQ-002-局域网多设备监控/requirement.md)：手机保存历史，默认开页直接看最新内容，联网正常且来源电脑可达时3秒内可见；旧历史按需翻阅。它与发送到电脑原记录的三秒门槛分别验收。

## 2026-10-05：最新页优先与本地连续段

本片已实施 D-44 的最新页优先路径。进入聊天先用现有无游标接口读取最新一页，成功后沿该页的尾游标读取新增；不再先补齐几小时前的全部缺口才交付首屏。原旧记录、旧页游标与待发状态保留在手机缓存，只有向上翻阅时才补旧页，没有新增 RPC、轮询器、自动重发或弹窗。此处是源码与合成回归结论，**实际默认开页和三秒内可见仍未验收**。

`TranscriptWindow` 在同一 owner 内保存最新连续段和归档段，段身份持久化为 UUID；原整数编号只属于当前显示段。旧 v1 缓存沿原字段无损读入，下一次原子保存为 v2，原 `TranscriptStore` 与64MiB正文总预算保持。最新页只有在来源完整且游标、顺序合法时才接受；`page_limit` 可继续原增量读取，但不能拿来建立新段，`source_discontinuity` 正文不使用。向旧页只在真实连续来源身份相接时复用缓存；完整内容已合并且没有页面引用的旧段才释放。

Runtime 与 ChatActivity 通过页面 token、连续段身份和阅读意图代次核对异步通知。默认新开页定位最新缓存；用户上翻、选择文字或跳到某条消息后保留原段和位置，通过原“回到底部”入口接受最新页。暂停恢复重新登记页面身份，迟到的旧页与同段旧意图均不能覆盖新页面。阅读位置保存来源消息身份与像素偏移；只有原生整数编号、无法证明所属段的初始跳转不再猜位置，改为显示最新。未新增日期搜索能力。

候选最新页的通知可能在动画期间延迟，真正接受后会从本地补齐这期间的新正文和待发对象，保持附件顺序、失败／accepted／unknown与原localId；不为补显示再请求网络或重投。来源回显在所有保留段中去重。独立复核发现的空段首条正文遗漏、书签切换前被清理、同段迟到滚动及候选等待期间消息遗漏均已修正。最后另发现页面转移与保存收集引用之间的并发缺口，已将引用收集和两类页面移交放在同一短同步区，三个引用各读取一次；序列化、磁盘与网络不进入该锁。

## 2026-10-05：提问直达、历史锚点和失效尾游标

本片沿已授权的手机易用性与 D-42／D-44 修复三个可复现问题，不增加功能菜单或自动弹窗：

- 纯提问与目标同时存在时，点击“查看题目”直接进入原问题表单；不再先绕到会话信息。混合审批仍保留原分流，目标详情仍可从聊天标题进入。
- 原 `loadMessages` 的 type3 使用排除锚点的旧页选择，导致请求某条消息却未交付该消息。现在使用 `TranscriptWindow.around` 返回包含锚点的双向邻近页，保持新到旧及页大小，首末从另一侧补齐。早于本地最旧记录的缺锚仍沿原游标、原队列最多补四页；普通 type0／1／2 保持。
- `readAfter` 明确返回字符串 `source_discontinuity` 时，原 watch 会反复请求已拒绝的同一尾游标。现在仅在原身份／游标守卫通过且非 bootstrap 时，将尾游标置空并保存已有缓存，随后沿原五秒失败间隔进入最新页与连续锚点恢复。拒绝页的正文和新游标均不接受；原消息、稳定编号与向旧游标保持。网络失败、坏字段、`page_limit` 和迟到回包不触发该失效处理。

## 后续同步与存储边界

当前watch有有效旧尾游标时从旧位置顺序追新增；缺尾游标时等连续旧锚找到后才发布。旧v5／v6或失效尾游标的source_discontinuity被拒绝后仍保留原游标，存在重复失败分支。这些是源码可达问题，不是本次现场v7已确认命中。

现有无游标page(older)接口可以直接取得最新一页及该次前向尾游标，无需新RPC。后续沿原TranscriptWindow／TranscriptStore单一所有者保存最新连续段、保留旧段和明确缺口；首个最新页可见不等待旧缺口。只在用户翻到缺口时补页，较旧分页不覆盖最新前向游标。来源身份稳定；现有原生正整数ID同时用于排序和分页，不能靠任意预留数字空洞冒充连续历史，接通缺口时须同步原生窗口及阅读锚点。当前该分段方案尚未实施。

源码检查：Direct Sessions正文page／readAfter由电脑原rollout提供；服务端delta仅ephemeral转发，关联保存元数据。普通persisted会话及显式takeover/import另有SessionMessage持久记录。因此本次direct路径与“手机缓存、服务器转发”方向相符，不能把路由Redis TTL误作已实现的短期离线队列；没有读取远端数据库／配置，未确认现场是否有旧导入全文，未删除任何服务器记录。
