# REQ-004 M0 技术验证记录（2026-11-11）

结论：**通过**（用户：“可以没问题”）。进入 M1。

## 做了什么

`qt/` 下只做一个悬浮球：原生版同一份点阵排版（逐行搬成 C++），自写点阵画布把方块直接交给显卡并对齐物理像素；透明、无边框、置顶、可拖动；彗星只在“在跑”时推进，停下后不重画；Mac 把底层窗口设成不激活的面板，Windows 加不激活、工具窗口属性。

## 顺带确认（T0.9）

- Windows 上 Codex 桌面 App（商店版）在清单里登记了 `codex` 链接，点任务跳转可用同一种链接。
- 那台没装 Claude 桌面 App，`claude://` 未验证；Windows 上钩子的命令环境留到 M3 实测。

## 偏差和遗留

- 设计写的是 Qt 6.8 长期支持版。Mac 磁盘只剩 16 GiB，改用本机已有的 Qt 6.11.2（PVTC 工具链，只读使用）；Windows 装同版本到 `D:\soft\Qt\6.11.2\msvc2022_64`。下载工具 aqt 3.3.0 不认 6.11 的 Windows 新目录，改为按官方 Updates.xml 下载、sha1 校验、7-Zip 解压。后续统一用 6.11.2。
- Windows 那台的 VS 2026 没装 C++ 编译器，改用同机的 VS 2022 Build Tools。
- Windows 的逐像素和占用数据没量，M3 打包后补。
- 测试数据、截图在 `.local/qt-m0/`（不提交）。
