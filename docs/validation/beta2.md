# beta.2：比例、字号与待处理提示

日期：2026-09-11。当前结果用于 beta.2，不覆盖 beta.1 的历史校验值。

## 实现

- 每个窗口依据实际 `NSScreen` 选择字号：外接屏紧凑，内置屏常规，暂时无法识别时保持原值；常驻浮窗始终紧凑。没有重建整个窗口根视图来切字体。
- 比例 60%–120%，每 5% 一档，共 13 档；旧偏好兼容。原生 `NSSlider` 使用整数百分比、连续事件、13 个刻度，更新偏好及恢复 100% 时同步滑块。圆环仍为 44pt。
- 60%–75% 的选择任务入口只显示加号，保留辅助功能名称与提示。辅助文字保持可读下限，低比例错误/提示区域保留足够高度。
- 用户确认的浅色提醒橙为 `(0.91, 0.43, 0.06)`，圆环和圆点同色；小标签使用 12% 淡橙底、黑色 82% 文字。浅色圆环加白色 36% 与提醒色 4%，不使用旧棕色底。
- 待处理后显示本轮开始至进入当前等待的时长；普通后续日志、重复等待不更新该时长。回答后清除当前等待时间，新轮重置。缺少可靠开始或等待时间时不估算；不是 CPU 时间，也不扣除本轮更早的等待。

## 实际运行核对

使用与发布应用同源码和可执行文件的独立截图副本，仅更改测试 bundle 标识及 Demo 标记，状态目录独立。README 中均为真实应用窗口截图，任务是合成示例，未公开私人任务或账户信息；正式包 `CodexTopDemo=false`。

已在实际应用核对原生控件的 60、65、70、75、80、85、90、95、100、105、110、115、120：控件值与可见百分比逐项一致，最大档可达；恢复 100% 成功。60% 展开头部为加号入口，任务选择窗口保留六行与取消/确认按钮；120% 展开列表可见。80% 的浅色、深色、常驻浮窗与 44pt 圆环已拍摄。

原生 Slider 的辅助功能设置值和可见滑块位置已核对。拖动工具多次报告窗口位置不匹配、用户已改变状态，或没有可核对的位移；没有把这些尝试记为鼠标连续拖动验收。顶部整片非按钮区域拖动、拖至上沿不切模式、跨屏收回锚点仍需完整鼠标复测。每个 5% 档位均设置过，不等于每档每个模式/屏幕均拍照验收。

单张截图与构建不证明 FPS、全部动画中间帧或完全没有抖动。物理拔插、合盖、Intel 真机和真实 A→B 登录切换仍未全面实测；任务/用量跳转终点边界见[完整对照](acceptance-matrix.md)。
