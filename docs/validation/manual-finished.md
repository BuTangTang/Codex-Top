## D-82 圆环开合流畅度

用户追加反馈“点击圆环展开／收起面板”不如之前丝滑。真实候选静置 CPU 采样约 70%–83%，主线程集中于 NSScrollView/NSClipView 的重复布局。隔离合成场景（13 条任务、105%、经典圆环含待处理、44pt 收起窗口）复现：20 次布局采样期间 clip frame 更新 108 次；相同条件下修正后为 0 次。

原因是经典圆环的呼吸 scaleEffect 施加在包含透明任务列表的整个容器上。修复只缩放可见背景、圆环、提醒角标和边框，隐藏列表仍挂载并保持固定尺寸；沿用原开合 spring 0.32/0.28、呼吸 0.9 秒半周期、共同透明度插值与窗口几何。该回归验证布局稳定，不能等同桌面完整 FPS 测量。build 38 候选在外接屏收起且待处理呼吸时的三个有效 CPU 样本为 18.5%、23.9%、38.0%；实时任务和系统负载不同，这些样本仅作现场观察，不作为严格性能基准。最终动画手感仍需用户确认。

用户对空“已结束”入口解释后答复“没事的，就这样”，因此仍在收纳数量大于 0 时才显示入口；未交付空入口调整。
