# D-73–D-75 展开响应、自动整理与菜单

2026-09-20，v1.0.0 build 27。用户反馈圆环与“已结束”点击卡顿、首次结束区开合后运行行和底栏抖动及底边重影；选择默认 7 天自动整理，并要求更多菜单不跟随面板缩放、实色深浅菜单、同层选项、向右展开和跟随系统主题。

## 实现

- 活动区 54pt、结束区 36pt，各自以同高懒加载列表并明确总高度，避免展开时创建全部历史控件，也避免重新引入混合行高估算。
- 列表内部不再逐行淡入/布局插值；窗口外框负责开合尺寸。标题优先保留空间，底栏保持固有高度；只有结束区箭头单独旋转。
- 设置增加关闭、3/7/14/30 天，默认 7。只有整段对话及子任务全部结束且最近活动达到期限才自动移出。未知、失败、运行、待处理以及缺少可靠时间都保留。
- 自动移出独立于手动排除。再次有活动可回来，“＋”手动加入后保留；关闭规则恢复自动移出的任务。仅改变本应用偏好，Codex 数据只读。
- 圆环模式不再使用系统窗口阴影；深色也不创建隐藏的玻璃视图。常驻浮窗保留原阴影。
- 更多菜单独立实色面板，按系统字号弹出，不继承短面板高度或比例。四种显示方式与三种主题分组直接列出，没有二级菜单或“收回圆环”；优先向右、空间不足贴可见边缘。设置和主题菜单新增“跟随系统”，监听 AppKit 外观变化并实时更新。菜单操作期间暂缓后台几何更新，关闭后应用最新内容。

## 自动验证与性能对照

150 项测试零失败。使用独立临时数据库与隐藏 NSHostingView，合成窗口从不显示在用户桌面。

| 项目 | 旧布局 | 新布局 | 解释 |
|---|---|---|---|
| 300 条合成任务展开结束区，三次 | 437/443/437 ms | 最终 37/33/35 ms | 调试构建，触发状态后让主线程处理失效与布局；含短暂 run loop 排空，受本机负载影响，不代表桌面 FPS |
| 300 条历史保留展开状态，圆环打开三次 | 175/200/139 ms | 最终 56/57/56 ms | 同一隐藏窗口 harness；不是鼠标点击到最后一帧耗时 |
| 21 条运行 + 79 条结束往返滚动 | D-71 完整栈保持确定高度 | 总高度变化不超过 1pt，回到顶部 y=0 | 未直接恢复旧混合 LazyVStack |
| 首次结束区展开/收起，重复两轮 | 离屏回归未复现用户报告的瞬态 | 每 50ms 采样运行圈顶部坐标与宽高，差值不超过 0.5pt | 仅验证运行行原生指示器，不冒充文字逐帧或完整底栏 FPS |

保留期限测试覆盖 7 天临界点、近期活动、所有非结束状态、活跃/近期/未知子任务、JSON 重启、手动恢复与排除、关闭恢复、重复刷新不反复加入、缺省值及缺失/非有限时间。既有来源只读、手动移出、批量选择、比例、计时、原生拖动等回归继续通过。

build 19 实机第一次开合时，54 条真实监控任务只创建 11 个任务按钮；初始与收起后的运行行端点位置一致。但用户随后指出底边仍有浅色重叠轮廓，不能将此版标为全部视觉问题已解决。后续修订让深色 GlassFill 彻底移除原生 NSVisualEffectView，不再仅把透明度设为零；新增隐藏窗口测试核对深→浅→深及调整窗口高度后，深色没有玻璃底层，浅色保留一层。

用户在 build 21、22 均反馈底部重影仍在；移除隐藏玻璃层、延后重算阴影未解决。build 23 关闭圆环窗口的原生阴影后，用户明确确认“重影消失了”；最终保留此处理，移除无效的延迟重算回调。

菜单回归覆盖 80% 与 120% 面板比例下系统字体和菜单尺寸相同、八个同级入口、设置/模式/关闭浮窗返回动作、无二级菜单及收回圆环、外接屏坐标及边缘裁限、深浅及自动主题外观与勾选。主题回归覆盖旧偏好默认深色、自动选项重启保持、手动配色不随系统变化，以及仅改变测试进程 AppKit 外观的深浅切换监听；不改系统设置，不启动真实任务或额度读取。

深浅菜单的隐藏真实视图像素采样均为 alpha=1，并核对深/浅底色。build 25 的原生菜单虽然深色已匹配，仍使用系统透明材质；用户否定后改为独立实色菜单。关于“列表自行左移”，当时本轮也在切换比例和跨屏验收，已经向用户明确说明，不能把测试造成的移动说成独立缺陷。随后停止移动的 45 秒记录只包含收起圆环，不能代替展开面板验证。

- 最终更新及菜单检查保留安装前的最新偏好；深色、圆环、100%、5 条、7 天及任务集合保持。期间用户自行移动的位置保留，不回写早期位置快照；没有在桌面展示 Demo 或操作 Codex 数据。
