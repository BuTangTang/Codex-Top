# D-78 双列快捷菜单

日期：2026-09-21。用户确认设计图后要求“不要顺带修改别的什么东西”。本轮只改更多菜单的渲染、尺寸和摆放；程序代码差异限于 MonitorMenuPanel.swift、MonitorMenuPresenter.swift。对应测试、构建号和本阶段文档同步更新。

## 结果

- 四种模式以 2×2 排列，主题为单行，设置在底部。固定宽 208pt、主字 12pt、选项行高 28pt；圆环菜单高 168pt，保留原有关闭/收起入口时高 196pt。
- 使用原 NSMenu 动作、选择状态和索引。视觉文案“浅色”“系统”仍对应完整的无障碍名称与原主题语义；设置、关闭浮窗、收起面板、上下/Tab、Enter/Esc 行为保留。
- 优先在来源窗口右侧留 8pt，顶部对齐；右侧不足用左侧，两侧均不足时仅把菜单裁限在屏幕内侧。极窄工作区的裁限仍可能覆盖来源窗口，不宣称任意空间都能完全避让。
- 任务列表、主面板字号、缩放、窗口控制器、动画、任务扫描与持久化逻辑没有本轮改动。
