# D-68：内置屏与外接屏统一字号

日期：2026-09-20。版本：**1.0.0 build 12**。

用户确认外接屏字号更合适，要求解决内置屏偏大问题。现统一采用原外接屏紧凑字号，窗口尺寸及用户缩放保持原样。

## 改动

- 窗口根视图从首次绘制起固定为紧凑档，环境默认值同步设为紧凑档。
- 删除依据窗口所在屏幕切换字号的原生探针和通知监听，跨屏不会再放大或缩小文字。
- 沿用既有紧凑字体算法，覆盖监控列表、顶部摘要、额度和任务选择器。常驻浮窗原本已是紧凑档，原生设置控件字号不变。
- 75% 比例下，两块屏幕标题/任务名/辅助说明均为 13/12/11pt；原按钮、行高、窗口尺寸和圆环保留。

## 验证与交付

- `swift test`：124 项通过、0 失败；`swift build -c release` 与 universal 打包通过，包含 arm64 / x86_64。测试使用既有合成样例；本次是固定字号环境和删除屏幕分支，不添加只断言常量的测试。
- 最终 build 12 已安装到本机正式应用，严格签名通过，安装后二进制与打包目录逐字节一致；ZIP 完整性检查通过。
- 内置 Retina（2×）和 Q27G10E2（1×）均以原 75% 比例核对圆环展开、长列表、额度和任务选择器。面板约 308 × 299 逻辑点，两屏文字布局一致；选择器均取消返回，未修改关注列表。
- 用户提出外接屏是否被放大后，临时退出新版并换回 build 11，在同一外接屏、同一比例下核对，再将旧包移到内置屏对照。外接屏旧/新文字布局一致；内置屏旧包长标题末尾省略，新包同一标题完整展示。随后恢复最终 build 12；整个过程只运行一份真实应用。
