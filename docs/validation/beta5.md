# beta.5：回复刷新、计时恢复与运行提示

日期：2026-09-11，对应 D-54–D-59。最终源码测试、通用包和列明实际窗口核对已完成；源码提交及发布回执由根代理收尾追加。下方候选结果与最终包结果分开记录。

## 实现

- D-54：仅监听已关注根任务所覆盖的待处理活动文件（包括子任务），最多 64 个，不读取正文。文件写入事件合并 200ms 后请求任务快照；扫描忙时保留请求并在结束后补刷。暂停、停止、切目录和取消关注时移除相应监听，保留原 2 秒扫描间隔。额度仍为独立 60 秒自动刷新。用户 `response_item/message/role=user` 与既有 UserMessage 事件一样解除等待，保留旧时间守卫。
- D-55：应用菜单提供 ⌘+/⌘= 放大、⌘- 缩小，复用 60%–120% 的 5% 档位；有键盘焦点的非激活监控窗口将这些键转交本应用菜单，无全局监听。缺少本轮开始时间的运行项显示 --:--，不由任务更新时间或当前时间估算。
- D-56：常驻浮窗隐藏顶部刘海；取消图钉恢复顶部。模式切换、定期布局、找回窗口等路径遵守同一互斥规则；状态栏入口与关注列表保留。
- D-57：仅对缺少开始时间、已追平且 running/waiting 的已关注主任务及任意层子任务，分批向前查找最近明确本轮开始，再临时按事件顺序重放到主 reader 当前 offset。每快照全部回查最多 8MiB、每任务最多 4MiB，逆向搜索与正序重放共用预算，64KiB 块/单行上限，候选轮转；游标跨轮保留，无固定总回查距离。兼容后只补 startedAt 及原 nil turnID，不扩大所有任务首扫尾部，不用 mtime、创建或当前时间估算，不覆盖当前状态/等待/主游标。找不到或尚未查完时保留占位，最近明确开始缺时间时不借更老轮次。
- D-58：“运行中”文字使用主题主文字色，深色亮白、浅色深色；蓝色保留给旋转环。紧凑浮窗也复用 TaskPhaseLabel，待处理/完成/失败配色、字号与尺寸不变。
- D-59：可见且允许动态的 NativeRunningArc 共享单调时间起点，以 1.2 秒线性周期旋转；补偿各自起始角与弧尾差，使可见前端对齐。新增/重新显示接当前相位；不可见或减少动态时停止，恢复重新对齐。既有主题、计数和悬停变化不重新启动旋转，无新增全局 Timer。

## 验证边界

源码独立审查覆盖刷新忙时合并、暂停/退出、目录代次、子任务与旧 inode 回调；新增临时文件监听和回复归约回归。真实记录只做只读时序/数量诊断，不将正文、标题和路径写入公开材料。

本机中途只读扫描样本含 736 个任务，冷读一次约 1.41 秒，后四次增量扫描约 77–95ms；这是 D-57 最终计时回查加入前的有限诊断样本，不是最终性能或回复到界面的时延保证。事件监听从本地完整记录落盘开始，不能缩短 Codex 自身写盘延迟，也不能保证系统负载下固定时延。首次状态尾读仍有 64KB 限制；D-57 的定向计时回查不能证明恢复了所有较早的未答问题。

共享相位的数学与源码核查不等于实际多帧同步或 FPS 通过。新增、隐藏/恢复、列表滚动和减少动态效果仍需按实际窗口分别核对；本轮不能用一张截图证明完全零抖动。既有物理屏幕、真实换号、导航终点和逐帧动画边界继续见 [验收对照](acceptance-matrix.md)。
