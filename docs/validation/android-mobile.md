## 2026-09-23 设置流程改版（局部验收）

设置改为账号与连接、通知、关于三个紧凑分组；新增云端连接、已连接电脑、通知设置、关于二级页，所有数据复用现有快照，不增加服务接口。系统返回与顶栏返回保持同一路径，返回系统通知设置后立即更新权限显示。示例增加三台电脑及单台离线，合成模式不允许开启后台提醒；真实后台仍为用户主动启动、最长一小时的现有实现。

Android 9 项单元测试、debug APK、测试 APK 与 lint 通过。独立模拟器 4 项设备契约测试通过，导航用例新增多电脑、离线、二级设置返回、合成连接标识及后台提醒限制断言。实际模拟器窗口检查浅色正常字号、深色 1.6 倍字体：标签和值在大字体时纵向排布，没有观察到重叠；检查后恢复模拟器默认字号和浅色。过程中模拟器 System UI 曾无响应，关闭其错误弹窗后恢复；不能将该现象写为应用崩溃或隐去。

小米重新连接后安装成功，实际点击进入设置并读取到分组与两台合成来源。随后手机出现来电，停止真机操作；含来电浮层截图已删除，不进入验收或公开材料。此次没有完成真机全部二级页、系统通知往返和锁屏测试。

完整对话界面、通知直达对话、真实 Codex 收发、多电脑跨网与阿里云部署仍未完成。设置页通过局部检查不能代替这些目标；当前安装包通知点击仍是旧详情流程，需在对话接入阶段替换。
