## 2026-09-10 补充：隔离数据源实机验收

使用应用自身的生产读取路径，QA 副本仅改变 bundle 标识和环境变量，关闭 Demo 标识；没有增加生产代码测试入口。通过 [Apple 的 LSEnvironment](https://developer.apple.com/library/archive/documentation/General/Reference/InfoPlistKeyReference/Articles/LaunchServicesKeys.html#//apple_ref/doc/uid/TP40009249-SW1) 设置已有 `CODEX_HOME` / `CODEX_TOP_STATE_DIR`，从 CUA 启动。数据为 `.local/` 中自行生成的 SQLite 和日志，未读取真实任务。已核对独立偏好文件产生、界面数据路径正确，正常应用偏好文件验收前后 SHA-256 相同。

- 设置 → 选择数据目录：改为不含数据库的目录，任务列表清空，明确显示“未找到 Codex 任务数据库”；再选择有效合成目录，待处理样例恢复，警告消失。
- 暂停刷新后向样例追加回答和完成事件，超过刷新周期仍保持原待处理状态，页脚显示“已暂停”；点击“立即刷新”后移入已结束区域，仍保持暂停标识。
- 新版日志包含 `task_started → task_failed → agent_message`，实际任务行保持“出错”，普通助手消息没有抹掉失败提醒。
- 暂时移走合成数据库，已关注任务改成“状态未知 / 数据源不可用”，不沿用旧状态；放回数据库后自动恢复失败状态、清除来源警告。
- QA 窗口退出，桌面 Demo 恢复。测试数据和 QA 包全部在被 Git 忽略的 `.local/` 中。

来源选择/暂停检查使用 `bcea145` 二进制；失败提醒和同目录失效恢复使用其后本次修订的 universal 二进制。上述是实际应用配合合成数据的结果，不替代真实日志事件变体、Codex 跳转终点和系统权限流程验收。
