# beta.3：主题扩散轮廓与双语说明

日期：2026-09-11。本记录只对应 D-52；beta.2 的比例、字号和计时验证见 [beta.2](beta2.md)。

## 修复

用户发现刘海面板切换主题时，两上角先于扩散波变色。旧主题快照统一采用四角 20pt 裁剪，与内置刘海面板的直角顶部不一致，提前露出了底下的新主题。

快照现在跟随实际表面：有摄像头避让的刘海面板只裁底部两角；刘海底角采用 `12 + 10 × progress` 的连续曲线；浮窗、选择器和菜单栏弹层用 `20 × uiScale` 的连续圆角；圆环保持 22pt 圆形曲线；设置窗口不加圆角。外形裁剪与原有径向遮罩取交集，点击扩散起点、时长和中断清理不变。
