## 额度修订

主界面只显示官方账户接口结果。历史日志快照单独放在设置的“历史日志额度（不代表当前账号）”折叠区，不能因日志较新而覆盖当前账号，也不能在账户读取失败时回填旧账号数据。

额度通过新的官方 CLI App Server 进程独立读取：自动间隔 60 秒、手动最短 5 秒、单次 15 秒超时。只初始化并调用 `account/rateLimits/read`，不启动对话或发送消息。暂停任务扫描不暂停额度；读取失败清空主余额并提示，目录切换丢弃旧回调。应用退出会取消并等待所拥有请求清理其 CLI，包含刚切换目录后仍在清理的旧请求。

[官方 App Server 文档](https://learn.chatgpt.com/docs/app-server)列出独立账户额度读取接口。本实现读取所选数据目录在该次 CLI 启动时的登录状态，不直接解析认证文件，也不宣称立即检测所有外部账户切换。换号后可手动刷新；未刷新前仍可能显示上次观察值及时间。
