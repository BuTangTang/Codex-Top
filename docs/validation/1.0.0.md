# 1.0.0 显示位置菜单验收

日期：2026-09-14。正式版本号 1.0.0，构建号 4。

## 交付内容

- 监控面板右上角增加一个“显示位置”入口，点击展开四种模式，当前项打勾；悬停说明与辅助功能值提供当前模式。
- 深色主题使用白色入口，浅色使用深色；保留图钉、任务选择、圆环收起及浮窗关闭按钮。
- 菜单跟踪期间暂停圆环外部点击收起和刘海离开收起，菜单结束后恢复，防止来源面板先收回而菜单仍独立悬着。
- 默认构建、ZIP 命名和当前说明同步到 1.0.0；历史版本及截图来源不改写。
