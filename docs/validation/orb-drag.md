# D-67：圆环展开抖动与拖动响应

日期：2026-09-20。版本：**1.0.0 build 11**。

用户反馈圆环展开后会抖一下，期间不能拖动。本次修复窗口坐标和动画期间的拖动，不改任务读取、状态判定、字体及两个标题按钮。

## 原因与修改

- 旧 `beginDrag` 在 `orbMotion` 存在时直接返回。拖动层已经记住本次手势开始，因此动画结束后也不会补发开始事件，必须松手再拖。保留原 spring，但取消输入锁；动画中的拖动同时平移原生画布、圆环锚点、展开终点和收回终点。
- 动画回调使用移动后的当前终点，并继续检查动画代次。按住拖动期间不裁切画布，松手后再收整；旧回调不能把窗口搬回拖动前的位置。收回期间拖动也清理旧展开方向，后续布局在松手后重新计算。
- 原生 NSPanel 在 Retina 上也使用整点窗口框。本机隐藏窗口探针中，合成请求 `(101.5, 200.5, 307.5, 298.5)` 实际变为 `(101, 200, 308, 299)`。旧圆环动画表面仍按半点端点布局，存在收尾不一致；现在圆环和面板预先采用与原生窗口一致的整点坐标。
- 对浮点运算接近整数的边界扣除数值误差，防止重复布局每次多长一整点；窗口和表面已在终点时跳过重复提交及阴影重算。

SwiftUI 的 `removed` 等待整个动画移除，可能晚于视觉上的完成，见 [Apple 动画完成条件](https://developer.apple.com/documentation/swiftui/animationcompletioncriteria)。本次不以固定延时解锁，也不把 spring 的 response 当作确定时长。
