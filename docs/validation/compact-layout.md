## 已确认范围

- 保留 D-68 字号、各模式宽度、主题、显示比例和“＋ / ⋯”入口。
- 停止、完成任务改为单行，保留状态图标、标题与状态文字；删除重复的结束说明和常驻跳转箭头，整行点击行为保留。
- 运行、待处理保留两行。标题使用整行宽度，第二行承载活动说明和计时或状态；出错、未知及未运行状态保留说明，避免隐藏原因。
- 已结束折叠按钮和账户额度合并为同一底栏，左右各自操作；暂停刷新保留可识别提示。
- 四种模式使用相同的任务行规则，窗口高度按可见任务的实际行高求和；可见数量、滚动、关注列表与状态来源不变。

## 实现

`PanelMetrics.rowHeight` 与窗口控制器共用行高规则：停止/完成 36pt，其他状态 54pt，分隔线另计；所有值继续按原显示比例缩放。常驻浮窗同样显示两行活动任务和合并底栏。

额度优先显示图标与完整摘要；窄宽度下去掉图标和双周期摘要的重复前缀，保留两个实际周期、百分比及过期提示。单周期采用“周剩余 …”形式；没有额度时明确显示缺失，不补造第二个周期。
