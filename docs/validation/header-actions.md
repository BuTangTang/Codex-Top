# D-64–D-65：标题栏与文字层级验收

日期：2026-09-18。版本：**1.0.0 build 9**。用户确认四种模式只保留“＋ / ⋯”，并授权完善整体字号、实现、提交 push 和更新 README。

## 最终变化

- 刘海展开、常驻浮窗、圆环展开与状态栏弹层共用两个入口：加号选择任务，更多菜单提供显示方式、主题、监控设置与收起/关闭。独立图钉和底部主题/设置入口已移除。
- 两个图标按可见宽度对齐，100% 下为 18pt，缩小后不低于 14pt；点击区域为 32pt，缩小后不低于 24pt。省略号由三个等径圆点绘制，原生 Menu 使用 button 样式以保留实际尺寸。
- 面板标题为 medium，任务名为 semibold，两者共用主字号。说明、计时、数量、已结束和额度统一小 2pt；额度采用辅助文字色。常规在 100% 为 16/14pt，紧凑为 14/12pt，最小分别保留 14/12pt 和 13/11pt。
- 关闭浮窗继续返回进入前的模式。关注列表、计时归约、读取来源、行高和圆环动画规则沿用既有实现。
