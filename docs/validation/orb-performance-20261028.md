## 改动

- 同一快照复用已解析父目录，下一轮重新验证；末级链接、目录、相对路径和异常路径仍完整解析，继续检查根目录边界。
- 路径分量采用ASCII查找；最多4096个、单项路径不超过1024字节的 URL 值对象复用。该缓存不替代文件元数据检查。
- 压缩输出按换行分段处理，保留64KiB单行、总输出和解码窗口限制。缺口、截断及超限不会被伪装成完成。
- 隐藏列表在350毫秒收起过渡后卸载；展开立即恢复。关闭动画与禁用计时独立控制。
- 不再因隐藏的关注范围统计变化触发窗口高度重排；整体来源错误照常提示。
