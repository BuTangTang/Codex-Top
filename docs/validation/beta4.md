# beta.4：设置跟随鼠标所在屏幕

日期：2026-09-11，对应 D-53。

## 实现

`showSettings()` 在激活应用前取得 `NSEvent.mouseLocation`，用当前屏幕的完整 `frame` 命中鼠标，因此菜单栏和 Dock 区域也参与选屏。未命中时依次回退到仍连接的原设置屏幕、系统 main 和首屏。

首次创建将目标屏幕传给窗口工厂，不先经过固定刘海屏幕的尺寸裁限。首次、关闭后重开或当前窗口未完整位于目标工作区内时，依据该屏幕 `visibleFrame` 居中并裁限；已经完整处于鼠标同屏内则保持位置。复用同一个设置窗口与内容，保留用户尺寸和滚动状态；关闭后重开仍收回监控展开区。没有修改监控显示器偏好或任务选择器的定位规则。

源码独立审查覆盖负坐标、菜单栏/Dock、不同屏幕大小、已有窗口重新进入和缺失屏幕的回退。实机范围与最终产物记录于下方；源码推理不能替代完整主副屏往返操作。
