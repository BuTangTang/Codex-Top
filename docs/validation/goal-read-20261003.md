## 读取修正

原冷路径为读取目标请求完整聊天历史，前台等待结束后返回未知；目标内容实际有单独的持久来源。新macOS路径先确认官方主进程持有对应来源IPC、唯一直接local app-server实际打开了同一路径／设备号／inode的目标库，并复核前后进程启动时间、命令和文件身份。多个窗口共享官方local连接，已独立核对。无法证明来源、多进程歧义、文件变化、超时及读取失败均保留unknown；只读打开，不创建、写入或迁移官方库。

来源核对使用1秒总预算，无重试、缓存和常驻子进程；查询沿现有STATUS只读取当前会话一行，不新增网络方法或手机轮询，不加载聊天历史。Linux保留原快照及冷等待方式。不带includeGoal的旧调用保持原行为，协议字段不变。异步读取后重新检查原lease与连接，断线结果不被标成当前可用。

最初按默认路径加配置扫描的候选被独立审查否决，最终以实际运行文件身份替代，未将该候选部署。源码阶段实际来源查询192ms；最终以正式包380ms回读为准。
