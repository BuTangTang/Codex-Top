## 后续操作约束

1. 先核对在线设备与活动 Android 用户；只能使用上述 Telegram 衍生包和明确入口，不按相似图标、显示名称或旧脚本默认值选择应用。
2. 安装时回读版本与完整 APK 哈希；启动后再核对前台包和实际页面。任何一项不符先停止该次验收，不能只凭构建成功或安装命令成功继续计时。
3. 模拟器启动检查是否加载旧快照；保留账号、历史、草稿和待发数据，不清数据或恢复旧快照来绕过问题。
4. 后续界面以用户最新指定的 Telegram 模板为基线。本轮记录现有偏差，未擅自移除之前选择的主题；逐项修正仍需实际截图核对。

实体手机、最新消息三秒、图片后文字发送、目标编辑及应用内升级完整闭环仍须分别验收，本次版本核对不替代这些结果。无生产代码改动，未重复构建或运行 Swift 全测；仅检查文档差异与本机界面。
