## 本轮修复

- 使用当前鼠标事件的窗口坐标转屏幕坐标，修复直接轮询全局指针时拖动位移不足。
- 吸附在 mouse-up 按最终 frame 重算，不依赖可能晚到的 windowDidMove 通知。
- 顶部拖动约束、松开后可见区域约束；普通点击不当作吸附。
- 圆环明确点击可以展开并接收键盘；收起释放键盘焦点。
- 取消每 16ms 修改 AppKit frame 的循环，改成 SwiftUI 表面动画及开始/结束边界更新。

## 尚不能标为通过

1. 真实指针仅悬停、跨应用悬停、快速反复进出、动画中断后的视觉连续性和实际 FPS。当前工具有点击/拖动，没有独立 hover 操作；端点截图和时长参数不代表帧率验证。
2. 系统“减少动态效果”开关后的实际行为；代码分支存在，但未为验收擅自改系统设置。
3. 物理外接屏拔插、合盖、重新连接、内置刘海屏及各缩放组合。
4. 状态栏计数胶囊的完整菜单栏截图与点击菜单路径；已证实模式转换/重新展开，不能把偏好值当成全部视觉证据。
5. 实际监控应用的真实任务跳转、无数据恢复、开机启动和权限处理；这些继续在 M3 验收。
6. Developer ID 签名、公证、Intel 真机与正式 Release。
