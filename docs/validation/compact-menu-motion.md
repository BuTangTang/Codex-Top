# D-76–D-77 紧凑菜单与浮窗动效

日期：2026-09-20。用户确认收紧菜单，并追加常驻浮窗展开“已结束”时整个界面抖动、四种显示方式切换需要动画。本轮按其“改动后提交push”指令交付源码和本机应用，不发布 Release。

## 实现

- 用户连续反馈宽度、字号和风格后，菜单最终从 196pt 收到 144pt，动作行 22pt、组标题 16pt、外边距 4pt；圆环菜单 226pt 高，带关闭入口的浮窗菜单 253pt 高。主字与图标为固定 12pt，深色统一黑底、12pt 圆角和淡细边，直接列出的模式/主题、独立于面板比例、优先向右展开保持。build 28 的 152pt/13pt 中途方案不作为最终交付。
- 常驻浮窗移除原生逐帧窗口缩放和居中内容缩放，改为固定原生画布、顶部左侧对齐的视口动画。运行行不随高度重新居中，底栏按视口高度移动；屏幕底部不足时限制列表高度并保留滚动。
- 目标坐标先归整点，重复刷新相同尺寸不重播；快速开合合并最新目标，拖动前收整，过期回调不能搬回窗口。动画期间暂时关闭阴影，收整后恢复，布局变更不记为用户拖动。
- 切换显示方式时旧界面淡出 0.10 秒，隐藏后调整内容和尺寸，再淡入新界面 0.16 秒，避免两份监控同时显示。快速切换以最新请求为准，减少动态效果时即时切换。
