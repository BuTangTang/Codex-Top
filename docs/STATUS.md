## 不可丢失的决定

1. 四种模式：顶部、常驻浮窗、44pt 圆环、仅状态栏。共用一份关注列表；图钉只切换模式。
2. 历史搜索/多选/全选当前结果；新建并开始的任务默认自动加入；手动排除优先；子任务归入主任务，完成折叠。
3. 背景和字体按 Atoll 参考：纯黑深色、系统白/中性灰字体；浅色玻璃保留可选。Atoll 独立克隆，只读参考，未复制代码/素材或安装运行。
4. 展开 410pt、浮窗 360pt；80/90/100 比例同步缩放，圆环保持 44pt；不能再把整个界面放大来弥补可读性。
5. 圆环/顶部悬停展开，常驻浮窗移开鼠标不隐藏。拖动手柄或圆环，顶部附近松手收进真正的系统状态栏。
6. 外接屏为正式功能：系统主屏/固定 UUID、无刘海回退、负坐标、拔插/合盖后找回。
7. Codex 只读；无 App Server 控制 socket 时使用落盘事件，不冒称跨进程实时状态；未知/过期如实展示；额度缺失不编造。
8. 不把认证、本机路径、真实任务标题/正文、原始日志或构建产物放入公开 Git。

## 当前实现与实测

M1 核心稳定。M2 的顶部/浮窗/状态栏/圆环、选择器、设置、配色、缩放已形成检查点。用户随后要求“圆圈本体放大，展开时不要另留圈”“单细环、悬停/运行/待回答/完成都有动画”。当前实现覆盖了这两个新决定：

- 圆环和任务面板共用一个 NSPanel，保存 44pt 原位锚点，0.26s 展开/0.22s 收回；展开时不留第二个圆圈，右上角按钮和 Escape 收回。显式收起抑制原地悬停立即重开。
- 单条 1.8pt 细环，无中心点/双层轨道/明显阴影；悬停微放大、蓝弧运行、琥珀待回答呼吸、红色失败、绿色完成合拢。面板展开后暂停不可见细环的重复动画。
- 演示设置有“动画预览”：运行/待回答/完成/出错，随时恢复示例状态。只影响合成任务，不持久化预览，不读真实 Codex。
