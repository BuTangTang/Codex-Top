## 不可丢失的产品决定

1. 一份关注列表供顶部、展开与浮窗共用。顶部图钉只切换显示模式，不为每个任务建立另一套钉住选择。
2. 历史任务搜索/多选/全选当前结果；新建并开始的任务默认自动加入；手动排除优先。
3. 紧凑行式列表，待处理优先，完成折叠，子任务归入主任务。
4. 外接屏是正式场景：主屏自动/固定显示器、无刘海回退、负坐标、缩放、拔插/合盖后的窗口找回。
5. 只读 Codex 元数据和日志，不读取认证文件，不复制任务正文到公开仓库。
6. 当前本机无 App Server 控制 socket。使用增量日志观察，不假称拥有跨进程实时状态；未知/过期必须如实显示。
7. 图中额度是概念值。实现读取日志里真实的 quota window，缺失时显示不可用。
