## 不可丢失的决定

1. 四种模式：顶部、常驻浮窗、44pt 圆环、仅状态栏。共用一份关注列表；图钉只切换模式。
2. 历史搜索/多选/全选当前结果；新建并开始的任务默认自动加入；手动排除优先；子任务归入主任务，完成折叠。
3. 背景和字体按 Atoll 参考：纯黑深色、系统白/中性灰字体；浅色玻璃保留可选。Atoll 只读参考，未复制代码/素材或安装运行。
4. 展开 410pt、浮窗 360pt；80/90/100 比例同步缩放，圆环保持 44pt。标题 17pt、任务名 16pt、辅助说明 14pt、搜索 16pt；不要因增大字体再扩大整个窗口。
5. 圆环点击才展开，悬停仅微动效；移开鼠标保持，点击面板外、收起按钮或 Escape 缩回。拖到顶部仍留桌面，右键复用菜单；仅常驻浮窗自动吸附。系统状态栏透明背景，左键开合任务、右键菜单。
6. 菜单栏弹层独立于顶部悬停模式：完整尺寸、0.96↔1 轻缩放与淡变；移开鼠标不自动收起，关闭后隐藏原生窗口，不留下黑色小胶囊。面板文字和外壳应用同一比例。
7. 外接屏是正式功能：系统主屏/固定 UUID、无刘海回退、负坐标、拔插/合盖后找回。
8. Codex 数据只读。任务来自本地数据库和落盘事件，不冒称跨进程实时状态；未知/过期如实展示。真实模式与 Demo 的数据、偏好保持隔离。
9. 点击任务返回对应 Codex 对话；点击额度打开官方用量网页。当前已安装 Codex 版本不支持外部原生用量子页深链，不能用设置首页冒充用量页。
10. 不把认证、本机路径、真实任务标题/正文、原始日志或构建产物放入公开 Git。
