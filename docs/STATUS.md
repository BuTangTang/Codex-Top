## 不可丢失的决定

1. 四种模式：顶部、常驻浮窗、44pt 圆环、仅状态栏。共用一份关注列表；图钉只切换模式。
2. 历史搜索/多选/全选当前结果；新建并开始的任务默认自动加入；手动排除优先；子任务归入主任务，完成折叠。
3. 背景和字体按 Atoll 参考：纯黑深色、系统白/中性灰字体；浅色玻璃保留可选。Atoll 独立克隆，只读参考，未复制代码/素材或安装运行。
4. 展开 410pt、浮窗 360pt；80/90/100 比例同步缩放，圆环保持 44pt。标题 17pt、任务名 16pt、辅助说明 14pt、搜索 16pt，窗口宽高不因字体调整而放大。
5. 圆环点击才展开，悬停只做轻微动效；移开鼠标保持，点击面板外、收起按钮或 Escape 缩回。圆环拖到顶部仍留桌面，右键菜单手动切换；仅常驻浮窗保留顶部吸附。系统状态栏透明背景，左键直接开合任务，右键菜单。
6. 外接屏为正式功能：系统主屏/固定 UUID、无刘海回退、负坐标、拔插/合盖后找回。
7. Codex 只读；无 App Server 控制 socket 时使用落盘事件，不冒称跨进程实时状态；未知/过期如实展示；额度缺失不编造。
8. 不把认证、本机路径、真实任务标题/正文、原始日志或构建产物放入公开 Git。

## 当前实现与实测

M1 核心已形成检查点。M2 的顶部/浮窗/状态栏/圆环、选择器、设置、配色、缩放已形成检查点。用户随后要求“圆圈本体放大，展开时不要另留圈”“单细环、悬停/运行/待回答/完成都有动画”。当前实现覆盖了这两个新决定：

- 圆环和任务面板共用一个 NSPanel，保存 44pt 原位锚点，0.26s 展开/0.22s 收回；展开时不留第二个圆圈。已移除圆环悬停展开/离开收回的计时器；外部点击监听仅在圆环展开时存在，并保留原点击的正常投递。
- 单条 1.8pt 状态细环，无中心点/双层轨道/明显阴影；浅色收起圆球加极淡中性边缘，帮助与白背景区分。悬停微放大、蓝弧运行、琥珀待回答、红色失败、绿色完成合拢。D-28 已改为需要处理时整个收起圆球 1.00↔0.94 缩放呼吸，每半程 0.9s；原生窗口保持 44pt，展开/处理完/减少动态效果时停止。D-28 仍待最终包实测。
- 演示设置有“动画预览”：运行/待回答/完成/出错，随时恢复示例状态。只影响合成任务，不持久化预览，不读真实 Codex。

本次继续修复：完成区内容与窗口高度使用同一状态；屏幕重排取消动画时同时恢复圆环局部坐标、44pt 窗口与焦点；设置/选择器阻止残留悬停回调。实机还发现活动项转入已结束后，部分行会保留旧图标，已改为单个稳定 ID 列表和直接观察最新状态的行，完成→运行往返实测通过。源数据方面修复失败提示被普通消息清除、旧轮次终止当前轮次、自动监控启用同秒的新任务漏加。
