# 手机客户端接口与实现边界

此为当前 Android 客户端消费的 v1 接口契约，不表示生产账号服务已实现或上线。所有接口同源；生产必须 HTTPS，禁止通过重定向转发密码或令牌。

## 登录与退出

`POST /api/mobile/v1/sessions` 接收 JSON：

```json
{"username":"自己的账号","password":"自己的密码","deviceName":"手机名称"}
```

成功返回 `{"token":"独立设备会话令牌","account":"账号显示名"}`。令牌应为 24–2048 位 URL 安全字符，客户端保存在 Android Keystore AES/GCM 加密的私有存储中。服务端必须自行实现安全密码散列、限流、会话有效期、账号隔离和受保护的初始化；fixture 不具备这些生产条件。

后续请求使用 `Authorization: Bearer <token>`。`DELETE /api/mobile/v1/sessions/current` 撤销该会话并返回 2xx，其他设备不受影响。客户端先停止本地提醒并清除凭据；撤销请求失败时提示“服务器撤销未确认”。

401 表示登录失效，手机清除对应会话；403、429、其他错误使用固定文案，不显示可能包含内部信息的服务端错误正文。请求有 8 秒连接/读取超时和 1 MiB 响应上限，不跟随 3xx 重定向。

## 完整任务快照

`GET /api/mobile/v1/snapshot`：

```json
{
  "version": 1,
  "serverTime": 1800000000000,
  "devices": [
    {"id":"source-1","name":"工作电脑","connected":true,"readState":"ready","observedAt":1800000000000}
  ],
  "tasks": [
    {"id":"task-1","sourceId":"source-1","title":"合成任务","project":"示例项目",
     "phase":"waiting","turnId":"turn-1","eventId":"event-2",
     "eventAt":1800000000000,"startedAt":null}
  ]
}
```

- 所有时间为 Unix 毫秒；`startedAt` 缺失时为 `null`。服务端不能用接收时间补造任务开始时间。
- `serverTime` 为响应时基准，客户端用单调时间推进；来源时间必须与该基准对齐。倒退的服务快照被拒绝。
- `readState` 为 `ready` / `paused` / `syncing` / 其他不可用值。`connected` 只表示来源连接，不能替代读取状态和观察时效。
- 来源连接正常、读取可用、观察时间不在未来且距基准不超过 60 秒，才计入实时统计；请求失败后展示上次数据并立即排除实时统计。
- `phase` 沿用桌面端 `running` / `waiting` / `completed` / `failed` / `stopped` / `idle` / `unknown`。陌生值显示未知。
- `eventId` 是同一轮状态事件的稳定标识；重复上报保持相同 ID 和时间，新事件有新的 ID 与严格增加的事件时间。没有可靠事件证据时传空值，不生成通知。
- 同一来源任务只保留一条已聚合的关注根任务，父子聚合由来源实现；手机不会重新发布或再次聚合来源任务。
- 来源 ID 与任务 ID 分别限 1–128 位字母、数字、下划线或连字符。复合身份为“来源 + 任务”，来源与同源任务不可重复。
- 每个完整快照最多 100 台来源、500 条任务。标题最多 160 字符，项目/设备名最多 80 字符；解析失败保留旧快照并显示错误，不发布半份结果。
- 不传会话正文、工具参数、完整本机路径、Codex 数据库或 Codex 登录凭据。来源名单由账号服务鉴权，不能依赖客户端过滤实现账号隔离。

## 客户端结构与通知

- `MainActivity`：原生登录、紧凑通知列表、详情与分组设置（含来源电脑状态二级页）；前台每 15 秒刷新，网络使用单工作线程，回调按页面代次丢弃旧结果。
- `MobileApi`：HTTPS 地址校验、登录/撤销、严格快照解析；UI 与服务不在主线程联网。
- `SessionStore`：只加密存储本服务会话；禁用云备份/设备迁移，不保存明文密码。
- `TaskData`：来源时效、状态语义、事件资格，纯规则可做合成单元测试。
- `MonitorService`：显式启动的 `dataSync` 前台服务，每 15 秒轮询，一小时主动停止；系统超时立即收尾，`START_NOT_STICKY`，不请求开机自启或电池豁免。
- `NotificationCenter`：常驻监控与任务提醒两个频道，任务通知默认通用文字、锁屏私密、两分钟有效期；停止或退出清理本应用提醒。

只有相邻快照中已有任务出现新的、有轮次和时间证据的完成/等待/出错事件，且来源有效、事件不早于两分钟，才通知；首次加载/新加入的历史任务不通知。每个任务只有一条当前提醒，旧等待解决、来源失效或任务移出时撤回；进程恢复重新建立静默基线，不补发历史。

一小时结束、系统省电或杀进程后均不承诺继续提醒。服务器持久事件游标、跨重启完整投递、扫码审批和手机远程操作不是本客户端初版的完成项。

## 手机交互选择

采用原生 Android Views，沿用仓库已有语义而不迁移桌面 SwiftUI。浅色使用冷灰背景 `#F4F6FA`、白色内容、深色文字 `#182133`；深色使用 `#14171D` / `#1E232C`。蓝、绿、黄分别表示运行、完成、待处理，所有状态同时写文字。系统中文字体跟随用户字号，不下载字体。

底部仅“任务 / 设备 / 我的”，详情使用系统返回；触控目标至少 48dp，内容可纵向滚动，给状态栏、键盘和手势区预留空间。示例与真实连接明确分开，空列表给出加入来源任务的下一步，不填充假任务。
