# Codex Top

原生 macOS Codex 任务监控工具。在刘海附近查看任务，也可以留下一个很小的桌面圆环或常驻浮窗。

**Beta 开发预览版，尚非稳定版。** 原生界面和本地只读数据接入已可运行，外接屏与完整动画验收仍在继续，详见[当前状态](docs/STATUS.md)。

## 下载

最新测试版：[v0.1.0-beta.2 下载](https://github.com/BuTangTang/Codex-Top/releases/tag/v0.1.0-beta.2)。安装要求 macOS 14+，DMG 为 Apple Silicon / Intel 通用包；打开后把 `Codex Top.app` 拖到 Applications（应用程序）。真实数据需要本机已有 Codex，额度需官方 Codex CLI 已登录。

测试包为 ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证，下载后可能被 macOS 拦截。版本内容、验证与限制见[发布说明](docs/releases/0.1.0-beta.2.md)。

## 四种显示方式

| 模式 | 使用方式 |
|---|---|
| 刘海模式 | 左侧待处理优先，右侧真实剩余额度；普通屏显示在上沿，悬停展开 |
| 常驻浮窗 | 紧凑任务列表，移开鼠标仍保留；顶部标题与留白可直接拖动，按钮除外 |
| 圆环 | 44pt 单细环常驻桌面；左键原位展开，右键打开菜单；移开鼠标仍保留，点击面板外、按钮或 Escape 收回 |
| 仅状态栏 | 透明背景显示运行/待处理计数，文字跟随系统明暗；左键显示任务，右键打开菜单 |

四种模式共用同一份关注列表。所有拖放都不自动吸附或切状态栏，菜单可手动选择“仅状态栏”。常驻浮窗和展开圆环的顶部标题、空白、上下留白均可直接拖动，按钮除外；展开圆环移动后，收起回到移动后的球位置。显示比例可拖动调整为 60%–120%，每 5% 一档，共 13 档，并可恢复 100%；圆环始终为 44pt。外接屏和常驻浮窗使用更紧凑的字号，60%–75% 时选择任务入口收成加号；一键切换纯黑与浅色玻璃时，新主题从按下的位置向外圆形扩散，底色与文字一起揭开。正常运行时蓝色外环旋转；需要回答或处理错误时，整个圆球轻微缩放呼吸，分别用琥珀与红色及内部 `!` 提示，中心仍是运行数量。展开或处理完后停止呼吸，全部完成显示绿色反馈。

圆环悬停仅有轻微动效，点击才展开；展开后不会因鼠标移开而收起，点击面板外、使用收起按钮、Escape 或切换显示模式结束。外部点击仍正常作用于原来的位置，常驻浮窗不会因此隐藏。顶部模式仍支持悬停展开和离开收起。

历史任务可搜索、多选、全选当前结果；新建并开始的任务默认自动加入。待处理优先、已结束折叠、子任务归入主任务。任务创建、输入和批准仍在 Codex 中完成。

点击任务返回对应的 Codex 对话；点击底部额度打开 [Codex 官方用量网页](https://chatgpt.com/codex/settings/usage)。账户额度自动每 60 秒更新，手动刷新最短间隔 5 秒，单次超时 15 秒；显示真实返回窗口与剩余，悬停查看来源、更新时间和重置时间。

## 本地构建

要求 macOS 14+ 和 Swift 6 工具链（Xcode）。无需第三方 Swift 依赖或 API Key。

```sh
swift test
bash scripts/build-app.sh
```

双击 `dist/Codex Top.app` 使用真实任务与额度。左键点击状态栏图标/计数直接显示任务，再点一次收回；状态栏和桌面圆环的右键共用菜单，可选择任务、改变显示方式、打开设置和找回窗口。应用激活时 `⌘,` 打开设置，`⌘T` 显示任务。

仅试示例界面时可构建演示包：

```sh
bash scripts/build-app.sh --demo
```

`dist/Codex Top Demo.app` 使用独立设置和合成任务，不读取本机任务或账户额度。从 Demo 改为实际使用时先退出 Demo，再打开 `Codex Top.app`，避免两份应用同时显示。

构建脚本默认使用本机架构和 ad-hoc 签名，尚无 Developer ID 签名或 Apple 公证。ZIP 打包和 universal 参数见[开发说明](docs/development.md)。

## 数据与限制

默认使用 `CODEX_HOME` 或 `~/.codex`，可在设置里选择其他 Codex 数据目录。应用只读本地任务元数据和增量日志；账户额度通过官方 Codex CLI 接口读取，认证由 CLI 管理。本工具不直接读取或复制认证文件，不上传任务内容。

任务状态来自已经落盘的记录，不等于跨进程实时状态。15 分钟没有新活动的运行记录显示未知；没有明确等待事件时不假称需要批准。仅存在于远程/云端、尚未同步到本机的任务暂不在接入范围。

主额度只用当前账户接口，日志单独放在“历史日志额度（不代表当前账号）”；读取失败不回填旧账号或日志余额。保留来源和更新时间，只显示实际返回的窗口，缺失的 5 小时额度不填造数值。“暂停任务刷新”不暂停独立额度读取；外部换号在下次实际请求时反映，不保证瞬时检测。Codex 内部格式可能变化，适配失败会提示。任务跳转终点、真实 A→B 换号及物理拔插/合盖尚未全部实测。

暖增量读取按预算顺序追赶，普通工具输出不会清除已建立的等待或轮次；积压时显示“正在同步任务活动…”。首次或记录重置后的有限尾读可能缺少较早未答事件，不能保证完整恢复。

只读诊断工具可用于反馈数量和耗时，不输出标题或对话正文：

```sh
swift build -c release
.build/release/codex-top-inspect
```
